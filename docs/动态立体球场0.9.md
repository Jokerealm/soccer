# 动态立体球场 0.9

2026-10-10。本轮把球场拆为高清地面细节、实时受光的草地、独立立体设施和动态场边资产，继续使用固定全场视角及二维比赛判定。

## 场景变化

- **草地**：独立圆角草地网格，混合原有高清地面细节与程序草纹、条带和细小法线。实时灯光与阴影继续影响草地；边缘少量真实草叶随风形变，中央保持清楚。
- **看台**：8 个三层看台模块、144 个独立座椅和 48 个挥手观众。台阶、座椅和栏边使用倒角网格、共享材质，观众使用立体身体和可动手臂。
- **旗帜**：8 面固定于旗杆的队旗，网格在顶点着色器中随风起伏，旗杆和飘动布面均为三维资产。
- **灯牌**：16 块带立体边框的 LED 灯牌，箭头和灯点持续流动；青／橙两套色调呼应队伍。
- **悬浮装置**：2 架场边摄影小无人机，悬浮、轻微转向，螺旋桨持续旋转并产生真实投影。
- **球网与进球反馈**：球门使用 50 条可形变网线。实际进球后，球网产生逐渐衰减的弹动，观众欢呼跳动、灯牌亮起庆祝色，并在进球侧释放有数量上限的彩色粒子。
- **灯光**：原有主灯与两侧补光继续工作；两侧补光缓慢变化，进球时稍微提亮。

这些动画由比赛展示时钟驱动；暂停同时冻结模型、材质动画和粒子，继续比赛后从当前状态恢复。重新开局、训练重置或更换持球目标会清除庆祝反馈。

背景插画保留，负责较远的建筑与装饰细节；本轮动画由实际模型、材质和粒子实时生成。GIF 是客户端动画的预览录屏，不是游戏运行时的背景素材。

## 规则与资源

新增场景物件不含碰撞体，不参与 Core 判定。踢球、铲球、武器、技能、100 生命／能量和 5 秒复活不变；常规足球仍在二维平面，场边动画不会启动高球。完整／精简 HUD 与低于 25% 的红色边缘保留。

模型、动画和着色器均为工程内可编辑代码，没有下载额外模型或新增 AI 图片。资源仍使用已有高清球场细节；材质与程序模型可继续换成正式美术资产。

主要入口：

- `Runtime/Presentation/DynamicStadiumView.cs`：草地、看台、观众、旗帜、灯牌、无人机、进球球网与粒子。
- `Runtime/Presentation/PremiumArenaView.cs`：基础灯光、三维球门和动态场景装配。
- `Resources/SceneSurface/LivingTurf.shader`：草地细节与受光风纹。
- `Resources/SceneSurface/ArenaWind.shader`：固定端布面／草叶形变。
- `Resources/SceneSurface/StadiumLED.shader`：滚动 LED 与庆祝色。

以上路径相对于 `UnityProject/Assets/Soccer/`。材质、网格按类型共享，庆祝粒子池上限为 96。
