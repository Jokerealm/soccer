# 对局记录与选角界面 0.24.0

首页与结算页新增“对局记录”。保存最近 50 场已完成的 AI 对练、局域网和互联网对局，点击列表可查看个人详情：胜负、己方／对方比分、角色、结束时间、比赛时长、进球、碰撞夺球、踢球、成功传球、击倒、被击倒、伤害、治疗与本局金币。

同一对局只保存一次，重复进入结算或接收最终快照不会重复添加；训练、教程、取消选人和未完成的对局不计入记录。记录按离线档／帐号分别保存在本机，关闭后仍保留，暂未云同步。本次只保存赛果和统计，录像与回放后续实现。

选角页默认模型缩小，留出更多空间；仍可拖动环绕、滚轮缩放、自动旋转和复位。右侧改为角色定位、一句简介和三个带技能图标的简短说明。主介绍不直接列生命、能量消耗、冷却等数字；需要时展开“查看技能参数”，查看当前角色的完整参数与机制。游戏中的技能悬停说明、按键设置、每局布阵和教程保持可用。

[Windows 0.24.0 试玩包](https://github.com/Jokerealm/soccer/releases/tag/v0.24.0)。完整解压后运行 `SkillSoccer.exe`。macOS 实际客户端验证记录保存／重载、入口、参数展开、模型操作及小窗口；双客户端验证双方各自的胜负、角色、金币和记录去重。Windows 实机与跨公网连接待实际试玩。
