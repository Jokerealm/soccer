# 二维规则与技能高球 0.7.1

> 此页记录 0.7.1 的规则修正。二维与技能高球约定继续保留，当前双角色与费用规则见 [枪兵与雷神原型 0.8](./枪兵与雷神玩法原型0.8.md)。

2026-10-09。按用户最新要求，游戏的常规规则相当于二维游戏；三维足球、球门、实时光照和阴影用于画面质感。只有未来特定的越顶技能启用球高，球门高度不参与规则。

## 当前行为

- 普通移动、传射、接球、抢断、身体阻挡与进球使用原有平面规则，普通足球没有上下运动。
- 球门只看平面净口、门柱和完整越线，不使用横梁高度判定；技能高球进门也按同一套平面规则得分。
- 删除通用 Shift + 左键挑球、L 越顶练习和普通蓄力的空中球路预览。玩家操作恢复为左键传射、右键武器普攻、Q／E 技能、空格抢断、C 取消、Esc 暂停。
- 现有三个试验角色没有越顶技能，当前试玩不会自动出现高球。角色设定与技能等待用户后续提供。

## 为后续技能保留的基础

`BallFlightMode` 明确区分 `Ground` 和 `SkillOverhead`。只有 Core 内部的 `TryLaunchOverheadSkill()` 可以按技能意图释放持球，并启用球高、竖直速度、重力和空中阻力；普通输入与 UI 不暴露这个入口。仅设置高度数值不会让普通球进入高球规则。

处于技能高球状态时，高度只用于球员接触与接球窗口：球可以从玩家头顶越过，足够低且正在下降时可接球。墙、门柱、原有护板和进球仍然遵守平面规则。具体技能将来若需要另外的例外，再按用户设定增加。

技能球第一次落地后立即清除临时高球状态，回到二维地面摩擦，没有后续竖直反弹。接球、进球、结束比赛、训练重置和持球者被击倒都会清除相关临时状态；暂停保留并冻结正在进行的技能高球。

三维显示继续保留。球门模型的高度属于美术参数，没有对应的 Core 球门高度字段。球体升起与地面软影变化只在技能高球模式下发生。
