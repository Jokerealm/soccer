# 无厘头角色与打击感原型 0.5

2026-10-09。方向来自本轮需求：参考《荒野乱斗》的舒适战斗节奏，以良子、奶龙、东北雨姐等熟悉的网络形象提供性格和技能灵感。先用这些参考测试好玩的打法，角色名单、技能组合和数值仍可调整。

## 想让玩家觉得好玩在哪里

足球把六个人聚到同一个冲突中心，攻击和支援改变传球机会。搞笑来自玩家做出的动作和临场结果：肚皮波弹墙绕后、锅铲贴脸压阵、队友喊着开席却先把球传出去。每个梗都要对应可操作、可配合、可反制的行为。

例如奶龙给低血接应者套上护罩，雨姐开工提速，良子先交球再开席恢复队友；下一轮对手也能等锅铲三连耗尽储备后反打。击倒只制造人数窗口，进球仍是当前胜利条件。身体碰撞、球路和弹体保持清楚，夸张反馈帮助玩家读懂命中。

## 手感目标与已经接入的规则

《荒野乱斗》的官方介绍强调短局 3v3 团队战斗，是本项目节奏的参考入口：[Supercell 官方游戏页](https://supercell.com/en/games/brawlstars/)。下面时间与数值是本项目的初始参数，需要真人试玩调整。

| 体验目标 | 当前实现 | 试玩时观察 |
| --- | --- | --- |
| 按下后迅速出手 | 奶龙前摇 60 ms，雨姐／良子 50 ms；120 fps 目标采样，60 Tick/s 裁决 | 点按是否觉得拖延，近身命中是否容易读懂 |
| 边走边打、持续修正位置 | 普攻、Q/E 与踢球的短动作后摇不暂停普通移动；眩晕、推移和突进仍按自身规则行动 | 躲弹和转向是否连续，后摇能否给人清楚的下一次动作预期 |
| 快速三次输出，再选择进退 | 三格普攻储备，奶龙／雨姐／良子攻击间隔 0.32 / 0.30 / 0.26 秒 | 三次连打是否有节奏；近战能否在远程空档接近 |
| 空档可以看懂 | 停火后按 1.15 / 1.10 / 1.05 秒补一格；新普攻重新计补充等待，补满三格停止计时 | 头顶三格与 HUD 倒计时是否便于预判；空格时是否仍能传球、抢断和放技能 |
| 短后摇里点按不会被吞 | 最多 120 ms 的普攻输入缓冲；只在已有储备、短冷却将结束时接收；执行时使用最新瞄准 | 快速点按是否可靠，取消、眩晕、暂停后是否出现意外攻击 |
| 命中有重量，也容易读懂 | 80 ms 闪白、120 ms 局部弹性压缩、出手回弹与武器亮点；浮动伤害数字 550 ms，同目标短间隔命中合并 | 6 人乱战是否仍能看清球、血条和敌我；散射是否显示有用的总伤害 |
| 不同动作有声音辨识 | 弹肚、锅铲、饭团各有出手声；伤害、护盾吸收和击倒各有短音；本地补充储备轻提示 | 连续攻击是否刺耳；不看 HUD 能否听出命中与挡住 |

普攻储备与技能能量是两种资源：普攻不消耗能量，Q 消耗 30 能量、冷却 5 秒；E 冷却 8 秒，奶龙／雨姐消耗 35，良子 30。所有角色仍为 100 生命、100 能量，速度 5 u/s、半径 0.5 u、踢距倍率 1。普攻的储备、射程、散射和前摇均可单独配置。

倒地后原地等待 5 秒，恢复满生命、满能量、满普攻储备并清控制、刷新冷却。1 秒复活保护与主动行动提前解除仍保留。短音、回弹、闪白和数字只影响表现，模拟时间和碰撞判定连续推进。设置中的命中反馈开关控制这些装饰反馈；弹体、近战范围、血条、储备和护盾仍可读。

## 接下来怎样判断舒服、好笑和有配合

先做三轮短局，每轮约 5 分钟：第一轮自由体验；第二轮要求每个玩家试一次“护罩接球 / 开工突破 / 开席撤离”；第三轮允许重复最喜欢的组合。每轮记录舒服程度、最想再做一次的动作、最容易看不懂的命中，以及被击倒 5 秒期间的感受。

重点比较空储备后是不是更愿意传球或躲避、弹墙绕后是否真的制造机会、锅铲近距离全中是否太强、饭团散射控制是否太容易命中。战斗笑点与合作次数比单看伤害更有价值。需要真人的判断来决定最终手感与英雄组合。

后续可以试验肚皮受击蓄力、锅铲推动足球、饭团治疗落点等更强的互动；这些尚未接入当前版本。先确认三种基础节奏，再加入会改变球权或反弹判定的新技能。
