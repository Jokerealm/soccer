# 技能足球 · UI 界面与交互说明

2026-10-13，对应 PC 原型 0.24.0。整体设计以最初的 [游戏设计文档](游戏设计文档.md) 为准；旧 0.4 说明保存在 [历史副本](history/UI界面与交互说明-0.4.md)。

## 页面与状态

启动加载 → 联网登录／离线进入 → 首页 → 开始游戏 → 模式选择。普通对战进入互联网／局域网房间，准备后进入每局选人布阵；AI 对练直接组好 AI 队伍再选人布阵。双方轮流选择角色及初始位置，全部锁定后热身、比赛、结算；暂不加入 ban。训练场可直接选择练习角色，新手教程直接进入 13 步可操作练习。角色展示使用实际 3D 环绕模型，设置支持自定义按键。公共自动匹配、排位和中继服务尚未接入；LAN 房间与本地部署登录／目录服务的房间号加入已实现。

`AppPage` 控制页面，`MatchDraft` 表示轮次、角色与开局位置，`TutorialSession` 表示教学进度；`MatchPhase` 控制倒计时／比赛／庆祝／结束；`MatchState.Half` 表示上／下半场，`Overtime` 表示金球加时。当前 AI 对练默认每半场 150 秒，顶部读真实阶段时间；训练显示“练习”，不走比赛时间。

首页增加商城入口与金币余额；上下方向键循环选择，Enter 确认，鼠标继续可用。商城提供英雄／皮肤分类、当前玩家余额与胜利获得金币的说明。结算页显示本局金币和余额，胜利奖励不会因重复打开结算而再次发放。

首页与结算页新增对局记录入口，列表选择后展示个人详情。选角模型默认缩小，右侧为角色定位和带图标的简短技能卡片，完整数值与机制收在默认折叠的参数区。

## 比赛界面

| 位置 | 信息 |
| --- | --- |
| 顶部中央 | 双方比分、当前阶段剩余时间 |
| 左上 | 训练／上半场／下半场／金球加时；精简时还有本人头像及生命、能量数值 |
| 右上 | 完整／精简 HUD 切换、暂停 |
| 透明场景上层 | 开球倒计时、进球、原地恢复、短状态反馈 |
| 底部居中 | 头像、角色状态、独立技能、公共动作、生命／能量 |
| 左下 | 半透明全场头像小地图 |
| 角色头顶 | 小型圆角生命／能量双条、必要的眩晕／恢复提示 |

相机占整个窗口，HUD 叠在球场上，底部没有黑边。头像与技能栏作为整体居中，枪兵六个行动格，雷神隐藏 G 后收窄成五格。面板背景约 64% 不透明，头像和文字独立保持清楚。精简隐藏底部栏，保留左上头像、两资源数值、比分、阶段、小地图。设置与比赛中均可切换并保存偏好。

角色资源只有生命（体力）和能量；头顶不再画黄弹药行、蓄力行或常驻 YOU。绿生命、蓝能量语义一致，小色标／脚底表示敌我。倒地隐藏双条并保留 5 秒原地恢复。底部不显示收到多少伤害；生命低于 25% 的外层红色渐变在两种模式都生效，中央透明，达到 25%、倒地或重置消退。

## 技能状态

冷却中的图标使用高清灰度资源，显示向上取整到 0.1 秒的剩余时间；环从顶部顺时针增长，按 `1 - 剩余 / 总时长` 完成一次完整圆周。完成恢复彩色、移除秒数、短暂点亮整环并给出就绪反馈。暂停时实际进度与数字冻结，不用另一个计时器估算。费用不足、倒地、热身禁用显示灰色与原因，不伪造冷却。

普攻格可以显示武器装填计时，这是动作状态，不是第三条角色资源。G 的数字表示自己的炸弹自动引爆时间，不是独立冷却。雷神 E 刷新 Q 时即时反映在图标、数字和环上。装饰反馈可关闭，冷却等必要信息保留。

悬停技能弹出名称、效果、生命／能量消耗、冷却和可用状态。关闭完整栏、暂停、换角或离场收起。鼠标在技能等交互控件上不会触发球场操作，在控件上释放已有蓄力会取消；地图节点不截获鼠标。恢复游戏清理按钮焦点和输入边沿，防止空格误点按钮。

## 操作、训练与验证

WASD 移动、鼠标瞄准、左键蓄力松开踢球（6 秒冷却）、空格铲球（5 秒冷却、扣生命）、右键武器、Q/E、枪兵 G 引爆、C 取消、Esc 暂停。短动作缓冲最多 120 ms，取消／暂停／失焦／受控清掉待执行输入。

训练工具放上方：R 重置，F 本人持球，T 目标持球，切换目标静止／移动，F1 判定显示，结束训练。只在训练生效，不能用来重置 AI 对练时钟或资源。

原生验证覆盖高分辨率图标、真实灰度、圆环进度与完成、秒数、暂停、两角居中、4:3／超宽／大窗口、小地图不重叠、开球、半场、恢复、低生命与终结进球；真实截图和报告保存在 reports/。完整设计更新必须同步最初总文档与确认单。
