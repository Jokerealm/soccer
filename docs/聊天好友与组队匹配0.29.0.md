# 聊天、好友与组队匹配 0.29.0

2026-10-15。保留 0.28 的热身六边形、四档 AI、Alt 信号、小地图和数字编队。本版加入文字聊天，拆分 Steam／游戏好友，并贯通游戏帐号、邀请组队、好友房间、普通匹配、服务端排位。

## 好友与帐号

首页右上角“好友”有两个分类：

- **游戏好友**：通过唯一游戏 ID 搜索，申请、接受／拒绝、撤回、移除；显示游戏名字和在线状态。可以复制自己的 ID、好友私聊、邀请组队或邀请到好友房间。申请与关系由游戏服务持久保存。
- **Steam 好友**：读取当前 Steam 帐号的好友列表，可打开 Steam 主页和管理好友。点击“邀请开房”会使用已有 Steam 房间，或先创建 Steam 房间，再通过 Steam 发出邀请。正常 Steam 邀请不依赖游戏社交服务。

游戏登录页可创建独立帐号：帐号为 3–16 位小写字母、数字或下划线，密码为 8–64 位，游戏名字仍为 1–6 字。服务器使用带随机盐的 PBKDF2 保存密码摘要；登录令牌为随机、带期限的服务会话，密码不写入客户端存档。

Steam 玩家可以通过服务器验证 Steam Web API 票据连接游戏社交服务；该路径需要开发者配置正式 AppID 和服务端 Web API Key。没有该配置时，Steam 玩家可在游戏好友页选择“使用游戏帐号连接 / 注册”，在保留 Steam 登录和房间邀请的同时使用独立游戏好友帐号。这里建立的是本次社交登录会话，不自动合并两个帐号的金币或历史战绩。

## 文字聊天

支持好友私聊、队伍聊天、房间聊天、对局队内及全场聊天。好友页“私聊”、组队大厅“队伍聊天”、好友房间“房间聊天”或聊天按钮都可打开。

- 比赛中 Enter 打开队内聊天；Shift＋Enter 打开全场聊天。输入框中 Enter 发送，Esc 收起，空消息按 Enter 也会收起。
- 每条最多 160 个 UTF-16 字符，服务器校验身份、长度、频道成员关系及发送频率。玩家文本按原文显示，不解释富文本标签。
- 私聊只允许已确认的游戏好友；服务器持久保存有界私聊历史，收件箱显示未读会话。队伍／房间聊天依据当前成员身份隔离，离开后不能继续读取旧频道。
- Steam／LAN／原互联网房间的房间、队内和全场聊天沿用现有房间传输，不依赖社交服务器。服务端匹配对局通过认证的 WebSocket 传输。
- 输入框获得焦点后，停止提交新的技能、传射、推抢、编队等按键动作，取消未完成蓄力；已有移动指令和联机比赛继续执行。

当前为文字聊天，未加入语音。每个会话最多展示最近 100 条；服务器总私聊存储保留最近 5000 条，队伍／房间聊天与在线状态为运行期数据。

## 组队、好友房间与匹配

首页“组队 / 匹配”或模式页“好友组队”进入组队大厅。队伍最多三人，有队长、在线和准备状态；邀请需要对方确认，邀请两分钟后失效。队长可以移出队员，离开后由剩余队员接任。组成队伍不会自动打断现有比赛。

**好友房间**：队长点击“队伍一起开房”，全队一起进入；邀请另一位队长或按房间号加入，会为他的整支队伍分配同队空位。房主可手动补 AI、选择四档难度；满六个位置且真人全部准备后，三秒倒计时进入每局轮流选人布阵。也可以不补 AI，邀请更多真人。房间通过游戏服务运行，不需要房主配置公网端口。

**普通匹配／排位**：全员在线并准备后，由队长选择模式。取消匹配、成员变动或掉线会取消当前队伍的排队。匹配把整支队伍放到同一队，凑齐两队各三名真人后开局，排位不使用 AI 冒充真人。人数不足时持续显示真实等待状态，没有虚假的“已找到”提示。

排位优先考虑双方平均排位分，等待时间增加后逐渐扩大分差范围。当前采用初始 1000 分、K=24 的队伍 Elo 原型参数；常规比赛不影响排位分。正式赛季、定级赛、段位美术及地区队列尚未加入。

## 服务端对局与结算

游戏服务运行 Core 的固定步模拟、碰撞、技能、足球和比赛时钟，客户端只提交自身输入并接收快照。服务器完成轮流选人，角色与位置校验、开场热身、比赛和最终结果；客户端无法通过上传结算页修改排位分。

排位结算按服务端比赛编号去重，并原子保存全部六名玩家的分数。普通好友房间和 AI 对练不结算排位。断线位置由 AI 临时接管；仍在本局的帐号可从组队大厅重新连接，重新连接会回到原位置。主动退出不会取消比赛或排位结算，当前比赛未结束时不能绕过限制开始另一场排位。

旧的本机金币、角色战绩及记录仍保留；普通战绩上传仍是原型客户端同步数据，与服务端排位分独立。

## 配置、版本和验证边界

协议升级为 `SkillSoccer/0.29.0/10`，联机双方需使用 0.29.0；服务端 WebSocket 握手也校验版本。游戏服务提供 `/api/register`、`/api/login`、`/api/friends`、`/api/chat`、`/api/community/*` 和受认证的比赛 WebSocket。

公共游戏帐号／好友／匹配服务尚未部署。游戏内好友、跨设备私聊、组队匹配和排位需要连接已部署的游戏服务；打包客户端中没有伪造在线好友、虚拟真人匹配或离线排位。Steam 房间、Steam 邀请、LAN、训练与 AI 对练继续可用。

服务器部署与存储说明见 [服务端说明](../server/DEPLOY.md)。验证报告位于 `reports/community-029-*`：独立帐号 HTTP／WebSocket 流程、六人两支队伍完整排位、真实输入造成的进球和分数变化、持久存储及原生渲染客户端检查。Steam Web API 正式凭据、真实好友邀请、Windows 实机和跨公网部署仍需在相应环境实测。

开发参考：[Steam 官方邀请与大厅](https://partner.steamgames.com/doc/features/multiplayer/matchmaking)、[Steam 用户票据验证](https://partner.steamgames.com/doc/webapi/isteamuserauth)。客户端只获取身份票据，Web API Key 只配置在服务器。
