# 调试帐号与 Windows 联机验证 0.17.1

2026-10-12。两台电脑均使用 0.17.1，完整解压 Windows 包后运行 `SkillSoccer.exe`。

下载：[Windows 试玩发布页](https://github.com/Jokerealm/soccer/releases/tag/v0.17.1)。选择 `SkillSoccer-0.17.1-Windows-x64.zip`，GitHub 的 `Source code` 压缩包是源码。

## 调试帐号

| 帐号 | 帐号密码 |
| --- | --- |
| a | a |
| b | b |

进入**普通模式 → 互联网 → 创建房间／加入房间**，先在页面中登录。推荐房主使用 a/a，客人使用 b/b；两个帐号均可创建或加入房间。帐号仅在当前进程中保持登录，重启后重新输入；房间内显示校验后的帐号身份。离开房间后可以退出帐号或切换帐号。

这是内置的公开调试帐号，没有注册、排位资料或云端帐号服务器。登录先在客户端校验，入房时再由房主用新随机挑战校验帐号身份。帐号密码输入框遮罩显示，提交后清空，不保存到本机设置或日志。

**帐号密码与房间密码是两个独立输入。** 房主可勾选“启用房间密码”并设置单独的入房口令；未启用时，客人的房间密码留空即可，仍需登录帐号。局域网模式不要求帐号登录。

## 两台 Windows 电脑验证互联网联机

1. 房主登录 a/a，创建互联网房间，默认端口 **TCP 27860**，任选枪兵或雷神、青队或橙队。先用无密码房间验证连接，之后再试开启房间密码。
2. 房主在 Windows 防火墙允许游戏用于联机的网络访问。若电脑位于路由器后面，将公网 TCP 27860 转发到房主电脑的局域网 IP、TCP 27860；房间改用其他端口时同步修改转发规则。
3. 房主填写并复制可访问的 `公网IP:27860` 或 `域名:27860`。客人使用另一个互联网接入（例如另一处宽带或手机热点），登录 b/b，输入该地址加入；密码房间再填写房主设置的房间口令。
4. 客人选队选角后点击“准备”，房主点击“开始比赛”。空位由 AI 补齐。双方分别移动、接球、蓄力踢球、使用技能，观察位置、球权、冷却与比分是否同步。
5. 客人按 Esc，确认只是打开本机菜单，房主仍可继续比赛。客人离开后，房主应看到 AI 接管；房主退出后，客人应收到断线提示。下一局由房主返回房间，客人重新准备。
6. 密码房间分别尝试正确、错误和空房间密码。帐号也可以退出后尝试错误密码，确认登录被拒绝。

互联网目前采用**公网地址直连**，没有云中继或自动穿透。房主必须具有可达的公网入站地址与端口；运营商 CGNAT 或禁止入站的网络可能无法作为公网房主。`127.0.0.1` 只连接本机，`192.168.x.x` 等私有地址主要用于局域网，它们不能用于验证跨互联网连接。相同路由器下访问公网地址还可能受路由器回环支持影响，跨网络验证更明确。

局域网的自动发现及完整房间操作见 [0.17 联机说明](局域网与互联网联机0.17.0.md)。

## 排查与日志

Windows 游戏日志默认位于 `%USERPROFILE%\AppData\LocalLow\Future City League\技能足球\Player.log`。也可从解压目录的 PowerShell 显式指定日志：

```powershell
.\SkillSoccer.exe -logFile "$PWD\online-test.log"
```

连接失败时记录页面提示、双方版本、所用地址与端口，以及房主是否有公网地址、端口转发和防火墙放行。登录成功仅说明调试帐号正确；公网可达性仍由实际网络决定。

开发验证使用真实 TCP／UDP 套接字及两个独立 macOS 客户端进程。Windows x64 构建通过后打包，跨公网和 Windows 双机结果由本次实际试玩复核。检查记录见 `reports/debug-accounts-0171-validation.json`。
