# 房间界面精简 0.19.1

创建房间默认只显示名称、“设置密码”和创建按钮。开启密码才出现密码输入框。昵称、角色与队伍收在“玩家设置”里，也可以入房后展开“角色与队伍”调整。

加入互联网房间默认只输入 6 位房间号并点击加入。“需要密码？”展开后填写密码；遇到密码提示时会自动展开。局域网仍显示附近房间，只列名称与人数；找不到时可以展开帮助，按房主 IP 加入。

大厅保留房间号与复制、队伍成员、准备和开始。隐藏重复的帐号、空位说明与邀请教程；AI 空位用一个简短标签表示。角色与队伍默认折叠，局域网备用 IP 放在展开区域中。

登录页的试玩帐号折叠显示；模式选择的连接说明缩为一句话。建房、加入与大厅使用居中的窄面板，保留滚动区以便展开选项，默认不铺满屏幕。

联网方式、房间号、密码验证与游戏规则沿用 0.19.0；0.19.1 与 0.19.0 房间协议兼容。公共互联网服务与中继仍待部署，离线局域网无需服务器。
