# 按键设置与三维选角 0.21.0

## 按键设置

在“设置 → 按键”中点击动作对应的按键，然后按新键。绑定自动保存在本机，重启后继续使用；“恢复默认”恢复原有键位。重复按键会提示并继续等待新键，Esc 取消本次修改，不退出设置。

可修改踢球／蓄力、推球／铲球、两个角色技能、提前引爆、取消动作、停止与备用停止、追加指令、暂停／比赛菜单，以及训练中的重置、持球、目标持球、判定显示、角球和任意球。追加指令可选择 Shift、Ctrl、Alt（左右键通用）或其他可用键。Enter、Tab 等保留给界面；Esc 始终可以返回或打开比赛菜单。

鼠标右键继续移动、跟随和追击；鼠标左键继续确认技能目标。技能栏、角色说明、悬浮提示、训练工具和操作提示同步显示当前绑定。本机配置适用于 AI 比赛、训练和局域网／互联网对局，不修改房间内其他玩家的设置。

## 三维选角

左侧选择枪兵或雷神，中间展示当前角色的实时三维模型，右侧显示属性和技能。模型使用实际比赛造型与材质，配有独立展示台、灯光与相机。

- 左键拖动：水平环绕与上下调整视角，拖动后暂停自动旋转。
- 鼠标滚轮：放大或缩小。
- 自动旋转：开关持续环绕展示。
- 复位：恢复默认视角和距离。

选中其他角色会更新模型与说明。进入比赛或离开选角后关闭预览镜头与拖动捕获。角色造型仍使用现有原型模型，未替换模型美术。房间号、自动端口、密码和比赛数值保留。
