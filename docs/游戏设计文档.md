# 合作乱斗足球——项目设计文档

更新：2026-10-13；对应客户端 **0.24.0**。本文是最初的设计文档，也是后续开发的总入口，合并历次角色、玩法、美术、球场、操作与 UI 要求。

**状态约定：**“用户已确定”来自明确要求；“当前实现／原型参数”描述可玩客户端，不代表数值定稿；“后续设计”尚未实现。旧 v0.8 全文保存在 [历史设计文档](history/游戏设计文档-v0.8-2026-10-08.md)，冲突处以本文为准。决策状态见 [关键设计确认单](关键设计确认单.md)。

## 1. 定位、角色方向与范围

用户已确定：强调合作、攻击、控制与传射配合的乱斗足球游戏，一人控制一角，目标仍是进球。角色有自己的武器、生命与能量，能攻击、震晕、击倒对手。先打磨玩法、手感和整体 UI 美术，再确定最终英雄与外观。

打击感参考《荒野乱斗》：移动连贯、响应迅速、短前摇、清楚命中与落空，通过动作、后坐、受击、音效、粒子共同表达。角色要好玩、好笑、带戏谑和无厘头感；良子、奶龙、东北雨姐等是形象与技能参考方向，用户会后续发设定，**不直接视为最终英雄名单或已完成资产**。笑点应通过技能造成的局面与合作发生。

技术已确定：Unity 体系的团结引擎＋C#，当前 **1.10.4 / 2022.3.62t16**。PC 优先，Windows／Steam 为目标平台；手机后续参考荒野乱斗摇杆，具体布局、平台及跨端匹配待验证。

当前可玩：13 步新手教程、自由训练、3v3 AI 对练、普通模式的局域网／互联网房间、枪兵与雷神两套临时参考打法，以及菜单、3D 选角、按键设置、暂停、结算、战斗与动态立体球场。房间最多六人，准备后由房主开始每局选人布阵，空位由 AI 补齐；互联网先向已配置的登录服务登录，调试帐号 a/a 或 b/b，房间密码独立设置。局域网可以离线进入。公共匹配、排位评分、公共登录／目录部署、Steam 好友和比赛中继尚未接入。

选人顺序为青 1、橙 1、青 2、橙 2、青 3、橙 3，每次 30 秒。角色以实际 3D 模型展示；布阵图选择边线内、中圈保护区外的本方位置，六人锁定后按所选阵容与位置开球。每局重新选择，房间不提前选角。完整流程见 [模式、选人布阵与新手教程](模式选人与新手教程0.22.0.md)。

商城已加入英雄和皮肤分类，当前两名初始英雄均已拥有，购买和装备将在后续接入。正式 AI／LAN／互联网对局胜利获 100 金币，同一局只发一次；训练、教程、失败、平局和退出不发币。离线玩家与帐号分别保存本机余额，暂未云同步。首页和模式页均支持方向键／Enter 与鼠标操作。详见 [商城与胜利金币](商城与胜利金币0.23.0.md)。

已加入最近 50 场完成对局的本机记录，按玩家档分别保存胜负、比分、角色、时间和个人统计，重复结算不重复记录；录像回放后续实现。选角以较小的可环绕模型、角色定位和短技能卡片为主，消耗和冷却参数按需展开。

## 3. 比赛、开球与时钟

| 阶段 | 当前原型 | 时钟／结果 |
| --- | --- | --- |
| 开场热身 | 3 秒 | 可以走动、瞄准；拿球与战斗禁用，不走比赛时间 |
| 上半场 | 150 秒有效时间 | 保留比分，半场结束不因领先直接结算 |
| 中场转换 | 2 秒重新开球倒计时，橙队开球 | 不走比赛时间；倒地玩家继续原地恢复 |
| 下半场 | 150 秒有效时间 | 非平局结束；平局进入加时 |
| 加时 | 最多 90 秒，金球制 | 首次进球判胜；到时未进球则平局 |
| 训练 | 无比赛时间限制 | 不触发半场或加时 |

“上下半场”表示比赛时间的两段，和球场上下两块区域无关。**半场方向来自用户；每半场 150 秒、2 秒中场转换、90 秒金球加时是沿用的可调原型值，尚未冻结正式时长。** 当前不交换球门；换边、中场休息长度、娱乐比赛的时长和加时规则待进一步打磨。

只有正式比赛进行时走有效时钟；倒计时、庆祝、定位球准备与等待主罚、本地暂停不走。顶部显示上／下半场或金球加时及当前阶段剩余时间；Core 保留全局剩余和累计有效时间。压哨进球先计分并完整庆祝，再进入下半场，不漏计、重复计分或误入加时。

进球原型庆祝 2 秒，然后 2 秒倒计时；失球方轮流由有资格的队员开球。全队倒地则中点自由球，不能提前复活。进球及中场重开重置存活球员的动作和资源，倒地者不移位、不缩短恢复；此重置方式可后续调整。终结比赛的进球先停止 Core，再显示最终球门庆祝，随后进入结算。

初始中圈与保护罩共用半径 **4.2 u／直径 8.4 u**，图形和阻挡也共用此参数；出生点在圈外。热身可走动转向，但不能穿入保护区，不扣资源、不储存攻击／铲球／技能／踢球输入。开球撤罩，保留热身走到的位置。进球重开的开球队员原型保护 1 秒，主动动作或过中线可提前结束；它与复活保护、重复控制保护独立。

## 4. 常规足球、操作与资源

单一真实足球，球权明确，脚前随行；球体完整越过有效门线计 1 分，乌龙算对方，允许带球入门。没有越位、点球和黄红牌；武器、技能和推抢均允许进攻。边界取消反弹，整个球越线后判出界，门柱保留真实碰撞。能行动的角色与自由足球或敌方脚前球碰撞即可获得球权，不必先使用推抢；接球后有 0.25 秒自动易手保护，普通队友不能碰撞抢走健康队友的球。普通球不设接球速度门槛；判定只读取角色半径与球半径，不设额外可接距离。被击倒、眩晕或推移中的角色不能主动接球。所有角色移动、突进和球都检查连续路径，避免高速穿过身体与门柱。枪兵半径 0.5、雷神半径 0.8、球半径 0.27 u；友敌均不可穿过，大体型影响可通过的间隙和挤压惯性，球的渲染与逻辑尺寸共用规则参数。

常规移动、持球、推铲、接球、进球只使用二维坐标。普通角色不跳跃，当前两角不启用越顶球；已保留特定技能高球接口，只有明确标记的技能球临时读取高度，落地立即恢复二维。后续越顶技能的费用、高度、范围、反制单独设计。

| 动作 | PC 输入 | 当前行为 |
| --- | --- | --- |
| 移动／瞄准 | 右键地面／鼠标 | 一次点击持续寻路；Shift 追加路线，S/H 停止；鼠标指定踢球与技能方向 |
| 踢球 | 左键按住后松开 | 点按短传、蓄力远传／射门；成功出球后 6 秒冷却 |
| 推／铲球 | 空格 | 身体碰撞后推开角色腾出空间；启动扣生命，5 秒冷却；不直接转移球权 |
| 武器／跟随 | 右键敌人／队友 | 有武器时追敌并进入射程自动攻击；友军和无武器角色跟随；右键足球追球 |
| 角色技能 | Q／E | 独立费用与冷却 |
| 枪兵引爆 | G | 提前引爆自己的炸弹；不是通用交流键 |
| 取消 | C | 取消未提交动作与移动／追击队列；取消踢球不启动冷却 |
| 暂停 | Esc | 单机真正暂停；联机只打开本机菜单，比赛继续 |
| 训练 | F／T／R／F1 | 自己持球／目标持球／重置／判定显示；F2 角球、F3 任意球，仅训练可用 |

生命（体力）和能量各 **100**，没有第三种永久角色资源。当前能量每秒恢复 12，施放后等待 1.25 秒；普通生命不自动持续回复。生命费用必须留下正生命，费用不足整次拒绝，不扣另一种资源、不启动冷却。

铲球消耗原型公式 `10 / 推力`，系数可调，反比方向是用户确定；枪兵约 16.1、雷神约 13.3 生命。启动只扣一次，命中／落空／碰保护目标均已支付费用；踢球和铲球各自冷却互不锁死。原型突进 1.8 u，前摇 0.06 秒、持续 0.15 秒、后摇 0.10 秒。

推抢只产生位移，不直接把球交给推者。推队友时，球权保留，足球跟随队友位移；从持球敌人的正面或侧面推时，敌人移开，足球以零速度留在原接触位置成为自由球，任何合格球员都必须实际碰撞这个自由球才能持有。从敌人的背后推时，球仍在敌人身上，并随人移动。

角度相对被推持球者的朝向和实际接触方向计算，不使用推者的瞄准夹角。当前背后保护扇区为左右各 45°，包含边界，宽度可调。完整保护与重复控制保护仍可阻止位移；推本身不直接转移球权；自动碰撞易手使用独立的 0.25 秒接球保护。普通推与炸弹击退共用带球／落球规则，炸弹方向来自爆心。碰撞夺走敌方持球或因推释放的自由球才统计“碰撞夺球”，更新最后触球者；推本身不记夺球。详细说明见 [0.16.1 更新](持球碰撞夺球0.16.1.md)。

武器不伤害队友。生命为零后掉球、停动作，原地等待 **5 秒**，恢复生命、能量、武器状态和冷却；原型复活保护 1 秒。倒地不能拦球、攻击、施法；进球和半场重置不提前恢复或传送倒地者。

武器内部目前有三次行动储备与逐格装填，制造输出空档；**这是武器动作状态，不是第三种角色资源，不在头顶画弹药条**。装填在普攻格提示，主 HUD 不显示弹药计数，蓄力用足球能量环及即时踢球提示，不增加头顶常驻条。

### 4.1 出界与定位球

整球越过边线判界外球，交给最后触球者的对手；整球越过底线且没有进球时，守方最后触球判攻方角球，攻方最后触球判守方球门球。记录传球者和最后触球者分别用于传球统计与出界裁定，身体挡球、接球、抢断也更新最后触球。二维球与技能高球共用平面出界判定；门柱碰撞先于后方越线，斜向出界按首次跨越的线裁定。

定位球选获球方最近的存活球员主罚，球队全倒地时等真实原地复活。球固定在主罚点，先准备 1 秒；对手距球至少 3 u 加自身半径，队友不占球体。主罚者左键瞄准／蓄力／踢出，AI 自动主罚；公共踢球冷却不妨碍定位球，但出球后仍开始 6 秒冷却。停球时暂停比赛有效时钟，球出手后恢复；不刷新全队生命、能量、技能冷却。

暴力足球保留武器、技能、推抢与铲球的合法性；不因这些攻击判任意球。定位球主罚者在别人触球前再次触球，判对方任意球，禁区内也用任意球，当前不做点球。任意球、角球可直接攻门；界外球直接入对方门判球门球，直接踢进本方门判对方角球。界外球暂复用脚下瞄准踢出流程，没有手抛动画。训练工具增加 F2 角球、F3 任意球。

右键操作借鉴星际争霸的地面移动、对敌攻击、友军跟随、Shift 路点和 S 停止。路径使用 Core 内圆形可见图 A*，按角色半径扩张障碍，动态重算，再由连续扫掠处理局部滑动；参考操作和行为，不声称移植原作内部寻路算法。详细规则与证据见 [0.15 更新](碰撞寻路与定位球0.15.0.md)。

## 6. 场地、立体美术与动态表现

| 项目 | 当前实现 |

| 球场 | **56 × 34 u**，左右对攻、对称竞技几何，普通镜头显示不下全场 |
| 球门 | 宽 4.5、深 1.5 u；门柱半径 0.10 u |
| 足球 | 判定半径 0.18 u，32 块立体皮面、凹缝、滚动、接触阴影 |

点按初速 9、满蓄力 18 u/s，地面减速 8 u/s²，蓄力到满默认 0.85 秒；持球移动为基础速度 80%，蓄力再乘 80%。持球减速比例参考用户提供的地图解包资料，传射参数仍是手感原型值；公共踢球冷却为 6 秒。进球镜头短暂展示实际得分球门，重开回到玩家，加时终结进球也完成庆祝后结算。

场景由图片／细节材质、三维几何、动态着色、实时灯光和阴影共同组成；单纯静态贴图或动图不作为整个球场方案。地面低反光灰绿／橄榄色，有草叶细节、磨损、风动和短暂脚印压痕，避免呆板绿条纹和刺眼反光。角色有立体体块、武器动作、受击、后坐；球门有立体门框、球网、阴影。光照不能盖住足球和场线。

当前环境动态：48 名观众、8 面旗、2 个无人机、16 组 LED、球网、草叶风动、16 个限额脚印。装饰不参与碰撞，密度与强度可以继续打磨。

蓄力能量环从薄荷色到金色；踢球有脚边冲击环、方向线、火花与短拖尾，强度跟随实际力度。正确球门处进球庆祝约 2.2 秒，含 11 面彩旗、96 片纸屑、12 条卷曲彩带、地面脉冲，球网／看台／LED 同步响应。使用对象池和单动态网格限制开销。暂停冻结场景动作，重置／开球／关闭表现反馈清理特效；保护、球权、冷却和低生命信息仍可读。拖尾和装饰不能成为第二颗真实足球。

## 7. HUD、美术和反馈规范

完整 HUD 默认给新手，底部小型半透明面板含头像、角色状态、技能及生命能量。**头像与技能栏整体水平居中**：枪兵六格、雷神五格，隐藏 G 后同步收窄重新居中；底距约 7 UI 像素，不压缩相机。背景约 64% 不透明，图标／文字独立保持清晰。入场短渐显、移动和缩放，就绪短亮光与少量粒子，统一色彩和节奏。

精简模式隐藏底部面板，左上保留头像与生命／能量数值，比分、阶段、时钟、小地图仍可见。右上按钮和设置页切换，保存本地选择；不影响资源、冷却、镜头、输入。

冷却使用原高清图标的实际灰度变体，中央显示剩余秒数，按 0.1 秒向上取整，未就绪不提前显示 0.0。圆环从顶部顺时针增加，`进度 = 1 - 剩余 / 总冷却`，完成刚好一圈；完成短暂整圈亮起、恢复彩色、清空数字，再隐藏圆环。读取真实 Core 数值，暂停保持信息进度不动。Q/E、踢球、铲球和普攻独立，空武器显示实际装填时间；雷神 E 刷新 Q 时立即完成。费用不足／倒地／热身禁用给灰色和原因，不伪造冷却。G 的数字表示炸弹引爆倒计时。

悬停技能展示名称、效果、费用、冷却、当前状态；暂停／换角／离场／关闭完整栏时收起，位置避开主要交战。原头像和技能资产保留高清，灰度生成保留尺寸与透明通道，不覆盖彩色原稿。

角色头顶只有两条常驻资源：上生命（体力）、下能量。当前一体圆角半透明暗底约 1.14 × 0.235 u，生命柔和绿、能量较细蓝；双方资源色一致，敌我由脚底和小色标区分，本地标金色。身高不同相应定位，受损有短残影，低于 25% 生命转柔和红色。移除黄弹药行、独立蓄力行、常驻 YOU 文字；倒地隐藏双条，显示原地恢复秒数，眩晕保留短状态提示。临时护盾／保护用角色效果，不增加永久资源条。

底部不显示收到多少伤害、不弹底部扣血数字；用动作、生命变化、短受击反馈表达。能量消耗的小反馈属于蓝条动作。低于 **25%** 生命时屏幕最外层半透明红色渐变，中心透明；≥25%、倒地、复活、重置消退，完整和精简均生效，关闭装饰反馈仍保留。

目前 31 个原创音频片段，主音量／音乐／音效分别调整保存，支持静音；武器、技能、传射、接球、进球、就绪对应真实事件，短音效声部最多 12 个。声音和特效不能与实际状态脱节。

## 8. 左下角头像小地图

半透明全场图，双方实时位置使用对应角色高清头像，青友方／橙敌方／金本地边框，1—3 队内编号区分重复角色。自由球显示浅色球点，持球头像带球徽；倒地头像暗化加叉，真实 5 秒恢复后复原。镜头框由实际相机向地面的投影计算，不用固定假框。

按真实场地坐标映射，训练两人／对练六人；随窗口适配，完整和精简均显示且不重叠居中技能栏。所有节点不截获鼠标，不妨碍瞄准。菜单、设置、结算隐藏；暂停冻结位置与镜头框。小地图和离屏足球提示共同支持大地图跑位。

## 9. 流程与后续设计

当前流程：启动／首页 → 训练或 AI 对练 → 两角选角和技能说明 → 热身 → 上半场 → 下半场 → 必要时加时 → 结算。训练可随时结束，设置、暂停、再来一局、回首页可用。

未来继续保留排位 PVP、普通匹配、合家欢娱乐方向：排位影响评分，普通共享标准规则而不改评分，娱乐强调夸张技能和朋友合作。正式人数、重复英雄限制、娱乐事件、娱乐时长、队列节奏待确定。**旧稿娱乐 4 分钟／铲球 2.3 秒、六角首发、固定全场镜头、32×18 球场不适用于当前版本。**

后续教学覆盖操作、传射、铲球费用角度、战斗协作、低生命复活、小地图与 HUD 切换；当前已有训练工具，完整分步骤教学待制作。AI 用于观察传球、追球、攻防和技能，不能替代真人平衡样本。弹力边界、巨型球、对称加速边路为历史娱乐提案，未接入标准比赛，未来遵守单一真球、清楚预警和双方公平。

私人房间已实现，支持局域网发现和公网地址加入；手柄、本地多人、手机平台和跨端属于后续范围。成长可研究熟练度、称号与纯外观；商业、售价、赛季、商城未定，不把付费属性增强作为玩法。排位匹配、断线重连、服务器运维和发行预算须在联机阶段继续细化。

## 10. 架构、验收与维护

Core 是规则入口，固定 60 Hz、4 次物理子步；输入转换、时钟、球权、资源、冷却和战斗由 Core 决定。模型／镜头／UI／音效读取状态事件，不反向更改判定。当前以房主为权威端：TCP 发送 60 Hz 操作与 20 Hz 完整快照，UDP 自动发现局域网房间；输入与快照校验、密码挑战、准备、离开和重开已接入。客户端按快照呈现，不依赖跨平台浮点确定性。云中继、预测和断线重连另行验证。详见 [0.17 联机说明](局域网与互联网联机0.17.0.md)。
