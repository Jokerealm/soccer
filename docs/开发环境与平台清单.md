## 1. Cowork、引擎编辑器和代码编辑器的区别

Tuanjie Cowork 是 Unity中国提供的开发辅助桌面应用，集成 AI 编程、调试及资源工作流。实际编辑场景、导入素材、运行游戏和构建应用，仍需要 Unity 或团结引擎编辑器；VS Code 用来编写和调试 C#。[Cowork 官方说明](https://codely-docs.tuanjie.cn/using-codely/codely-cowork/)

团结引擎属于 Unity中国的引擎产品，与 Unity 国际版有共同技术基础，但发行版本与部分功能、包兼容性存在差异。同一个工程固定使用同一发行版和版本，安装后记录 `ProjectSettings/ProjectVersion.txt` 与 `Packages/packages-lock.json`。[团结引擎手册](https://docs.unity.cn/cn/tuanjiemanual/Manual/)

当前检查到 Cowork 2.1.2-stable、团结 Hub 1.4.6、团结编辑器 1.10.4，以及 Unity 编辑器 2022.3.62f3c1。团结编辑器位于 `/Applications/Tuanjie/Hub/Editor/2022.3.62t16/Tuanjie.app`；自定义安装位置可通过 `SOCCER_UNITY_EDITOR` 指定后重新检查。

## 3. 编辑器与模块安装入口

### 3.1 团结引擎与 Windows 模块：本机已完成

1. 打开 Cowork，若当前版本提供编辑器安装入口，可从该入口管理安装；否则使用团结引擎官方提供的安装管理器。登录用户自己的 Unity中国账号。
2. 在 [团结引擎官方下载](https://unity.cn/tuanjie/releases) 选择 **游戏开发用稳定版、macOS Apple Silicon**。版本页同时可能包含 HMI／车机版本，游戏项目采用面向游戏开发的版本。
3. 已安装编辑器后，在 **团结 Hub → 安装 → 1.10.4 右侧「安装设置」→ 添加模块 → Windows Build Support (Mono) → 安装**。本机已经完成，Hub 显示「已安装」，文件与 win64 Mono Player 也已检查。该模块下载 334.41 MB，占磁盘 389.76 MB。Windows IL2CPP 的原生编译需要 Windows 构建机上的 C++ 工具及 Windows SDK，后续再准备。
4. 完成编辑器所需账号／许可激活，启动一次并确认可以创建 2D 工程。安装模块必须与编辑器同版本。
5. 本项目当前使用团结 1.10.4，之后客户端、服务器及协作者使用相同版本。如果要为另一套 Unity 编辑器添加模块，入口为 **Unity Hub → Installs（安装）→ 对应版本右侧齿轮／Manage → Add modules（添加模块）**；各版本独立管理模块。[Unity Hub 官方步骤](https://docs.unity.com/en-us/hub/add-modules)

官方模块管理方式见 [团结引擎 Build Settings](https://docs.unity.cn/cn/tuanjiemanual/Manual/BuildSettings.html)，Windows 原生编译要求见 [Unity 系统要求](https://docs.unity3d.com/cn/current/Manual/system-requirements.html)。编辑器和构建模块通常合计数 GB，下载体积以安装器为准。
