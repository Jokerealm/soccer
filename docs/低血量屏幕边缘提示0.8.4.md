# 低血量屏幕边缘提示 0.8.4

2026-10-10。角色生命低于最大生命的 25% 时，屏幕最外围持续显示半透明红色渐变。当前两个角色最大生命均为 100，因此低于 25 点触发；恰好 25 点不触发。

红色沿屏幕四边向内渐隐，宽度为窗口短边的 5.5%，最外缘为 42% 不透明度，中央完全透明。进入和退出均有约 0.25 秒过渡，持续低血量时保持稳定。回血到 25% 或以上、被击倒、重新训练或离开比赛后清除；5 秒复活恢复满血后不会残留。

完整与精简 HUD 都能看到提示。它属于生命状态信息，独立于“命中反馈”开关。头像、血条和左上角生命数值的低血量提示也统一为低于 25%。已有短暂受击闪红仍独立工作。

实现位于 `UnityProject/Assets/Soccer/Runtime/UI/HudMotion.cs` 的 `LowHealthVignette`，使用 UI Toolkit 网格画出渐变边缘，不依赖新的图片，也不拦截鼠标。战斗规则与角色技能数值未改动。

macOS 实际客户端验收证据：

- `reports/runtime-ui-084/21-low-health-full-hud.png`：完整 HUD 的低血量提示。
- `reports/runtime-ui-084/22-low-health-compact-hud.png`：精简 HUD 的低血量提示。
- `reports/runtime-ui-084/runtime-smoke.json`：25% 边界、持续显示、实际边缘与中央像素对比、模式与反馈开关、回血、击倒和复活检查。
- `reports/ui-084-validation.json`：构建与运行结论。

Windows 构建仍需在 Windows 设备上运行验收。
