# 三维方向与高球原型 0.7

> **已由 0.7.1 修正**：用户明确常规玩法应保持二维，只有特定技能启用高度。通用 Shift 挑球、L 越顶练习与横梁高度规则已撤掉。当前实现以 [二维规则与技能高球 0.7.1](./二维规则与技能高球0.7.1.md) 为准；本页保留此前原型记录。

2026-10-09。用户希望加强三维感，并为以后能把球踢过头顶的技能做准备。本轮先按固定斜俯视的 **2.5D** 方向实现可玩的基础挑球；完整 3D、角色跳跃与具体英雄技能尚未冻结。

## 方向

场景灯光、足球和球门采用真实三维显示，角色仍在平面球场走位。足球拥有地面位置、离地高度与竖直速度，飞行和碰撞由规则层控制。这样能支持越顶传球，而不需要先决定所有角色模型或改为自由镜头。

当前球场的看台和周边细节仍来自地面图片，所以整个场景尚未全部改成三维建模。角色继续使用玩法棋子，没有提前确定英雄外观。后续若选择完整 3D，可继续扩展这些高度状态和碰撞规则，并制作三维环境／角色，而无需再次重写球的飞行基础。

## 直接试玩

1. 进入训练场，点击 **L 越顶练习**，或按 L。它会把球交给你，并在前方安排静止目标。
2. 按住 Shift，再按住左键蓄力；松开左键挑球。越顶练习里向右瞄准即可试着把球挑过目标头顶。
3. 普通左键仍然传射，右键武器攻击，Q／E 保留原有试验配置。挑球模式在开始蓄力时锁定，途中松开 Shift 不会突然切回地滚球；C、暂停或受控会取消蓄力。

蓄力时显示空中弧线和首次落地点圆环；飞行时显示上升／下落提示。足球模型按高度升起，地面接触软影随高度变淡、变大，实时投影仍由灯光生成。球路预览用于无遮挡时的参考，实际碰撞与反弹会改变落点。

## 实际规则

- 球的高度是球底离地距离，地面为 0。高球使用独立空中阻力；落地时按重力计算时间、反弹并损失水平速度，之后恢复地面摩擦。
- 高于身体阻挡高度的球可以越过地面玩家和原有地面护板。低球仍会与身体接触；只有足够低、正在下降或已落地、速度在接球范围内的球可以被接住。
- 进球需要整个球从球门内越过门线，并低于横梁。横梁使用带高度的扫掠接触，可让球反弹。越过横梁的球不算进球，门后空间保留封闭球场的回弹边界。
- 暂停冻结高度和重力；接球、训练重置、重开球和持球者被击倒时清除相应飞行状态。
- 飞行仍使用固定 60 Hz 权威模拟和物理分步，显示层插值高度。没有把可玩规则交给动画或 Unity Rigidbody，便于保持现有规则测试和后续同步。

| 参数 | 当前试验值 |
| --- | --- |
| 重力 | 18 |
| 空中水平减速 | 0.6／秒 |
| 挑球竖直初速 | 8–11，随蓄力增加 |
| 挑球水平速度倍率 | 0.8 |
| 身体阻挡高度 | 1.25 |
| 自动接球高度 | 0.3 |
| 横梁高度 | 2 |
| 落地竖直反弹系数 | 0.32 |
| 落地水平速度保留 | 0.82 |

这些都是原型数值，不是正式英雄技能平衡。身体接触仍采用水平扫掠与高度范围近似，没有头部表面物理；机器人沿用地面传射，尚不主动挑球。当前没有实现角色跳跃、主动头球、空中接球技能或空中武器攻击；后续可以围绕球的高度、轨迹和接球窗口设计。
