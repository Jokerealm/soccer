# 个人主页、好友与房间准备 0.25.0

首页“个人主页”展示累计场次、胜率、进球，以及枪兵／雷神各自的场次、胜负平和胜率。点击角色卡片可筛选最近战绩，点击“战绩详情”进入原有最近 50 场详细记录。累计数据不会随最近记录滚动而减少，离线档与帐号分别保存在本机；旧版存档以仍保留的记录初始化累计统计。

首页右上角和个人主页可进入“好友”。联网登录后，输入帐号 ID 查找玩家、发送好友申请；对方可接受或拒绝，申请可撤回，已添加好友可移除，也可打开好友主页查看角色数据和最近战绩。好友关系和已同步的帐号战绩保存在登录服务，服务重启后保留。目前账号仍使用调试帐号 a / a、b / b，注册和正式帐号系统尚未接入。离线可查看自己主页，联网好友操作需要可用的登录服务；本机统计在同步失败时仍保留。

新房间的空位默认显示“空位”。只有房主能逐个添加／移除机器人，也可使用“补齐机器人”“清空机器人”。沿用 3v3 规则，六个位置由玩家或房主手动添加的机器人占满后可以开始，机器人自动就绪。房主也需要点击“准备”；全部真实玩家准备后，全员同步显示 3、2、1 倒计时，再进入每局的选人布阵。取消准备、调整队伍、变更机器人或玩家离开会取消倒计时，重新检查阵容与准备状态。重开时保留房主配置的机器人，玩家需要重新准备。

同局玩家请使用 0.25.0，房间协议已升级，旧版本无法混用。比赛进行中的断线球员仍由 AI 接管。录像回放仍未实现。

下载 [Windows 0.25.0 试玩包](https://github.com/Jokerealm/soccer/releases/tag/v0.25.0)，完整解压后运行 `SkillSoccer.exe`。公共登录、好友服务与比赛中继尚未部署，实际联网验证使用本地服务；Windows 实机与跨公网环境待试玩。
