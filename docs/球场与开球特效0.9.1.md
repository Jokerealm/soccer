# 球场与开球特效 0.9.1

2026-10-10。针对过亮的青绿地面、左侧大片亮斑和不协调的倒计时牌，调整实际游戏场景与开球 UI。

## 球场

- 草地改用低饱和的森林绿与鼠尾草绿，割草条带保持轻微明暗差。
- 原球场图片只提供细纹理，局部均值过滤移除图片中烘焙的大片高亮与青色色偏；加入细草纤维和少量风动法线。
- 草地使用无镜面高光的哑光材质，继续接收实时光照和模型投影。
- 两侧补光从场内低位移到更高的场边，降低亮度、色偏和动态提亮幅度。球、球门和角色保留立体受光。
- 门区标线提高对比度，四角补齐细角球弧线。保留看台、观众、旗帜、灯牌与无人机动画。

同一 1920×1080 实际全场截图的左右两块空草地采样区域：旧版平均亮度为 0.882 / 0.724，新版为 0.450 / 0.444；左右亮度比由约 1.22 降为 1.02。这是具体截图区域的对比，并非全场所有像素的均匀度指标。

## 开球 UI

移除原来的米色实心倒计时牌。新 UI 使用透明底、暖白数字、青绿进度环、金色刻度与轨道；每次 3 → 2 → 1 切换时数字轻微弹入，光环向外扩散并释放少量粒子。结束时短暂显示“开球！”，随后在 0.64 秒内退场。

数字与进度环直接读取 Core 的剩余倒计时时间；暂停时数字缩放、粒子和轨道一起冻结。完整和精简 HUD 都显示开球信息，反馈开关关闭时保留数字与进度信息，关闭装饰运动。进球文字也去掉原有实心卡片；原地复活仍保留独立提示。

所有新图形由 UI Toolkit 网格生成，无新增下载素材或 AI 图片。主要代码：

- `UnityProject/Assets/Soccer/Resources/SceneSurface/LivingTurf.shader`
- `UnityProject/Assets/Soccer/Runtime/Presentation/PremiumArenaView.cs`
- `UnityProject/Assets/Soccer/Runtime/Presentation/DynamicStadiumView.cs`
- `UnityProject/Assets/Soccer/Runtime/UI/CountdownPresentation.cs`
- `UnityProject/Assets/Soccer/Runtime/UI/{GameUI,HudMotion}.cs`
- `UnityProject/Assets/Soccer/UI/{Game.uxml,Game.uss}`

普通二维玩法、两种角色技能、独立冷却、生命与能量、5 秒复活、HUD 切换和低于 25% 的红色边缘保持原有规则。
