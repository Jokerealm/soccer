# 技能足球 · UI 界面与交互说明

2026-10-09 · 对应 PC 战斗原型 0.4

## 1. 页面和实际入口

| 页面 | 入口 | 主要内容 | 返回 / 下一步 |
| --- | --- | --- | --- |
| 启动 Loading | 启动 | 原创封面、真实资源预加载、提示 | 自动进入模式选择 |
| 主菜单 Home | 加载完成或返回主菜单 | 普通、排位、娱乐三张模式卡及训练/图鉴/设置工具 | 模式详情或本地选角 |
| 模式详情 ModeDetails | 点击模式卡 | 玩法、互联网/LAN、联机可用状态、本地训练入口 | 返回首页或选角 |
| 选角 CharacterSelect | 训练 / AI / 图鉴按钮 | 三套测试装备、生命／能量、武器与 Q/E 说明 | 开始当前模式或返回 |
| 比赛 Match | 选角后开始 | 比分、有效时钟、持球、冷却、反馈 | 暂停、自然结束；训练可主动结束 |
| 暂停 Overlay | Esc、暂停按钮、窗口失焦 | 继续、重新开始、返回主菜单 | 恢复或退出当前对局 |
| 结算 Results | 计时结束、金球进球、结束训练 | 比分、有效时间、本人进球/抢断/踢球/传球 | 再来一局或返回 |
| 设置 Settings | 主菜单 | 总音量、音乐/音效音量、静音、特效开关与键位说明 | 返回主菜单 |

页面显示枚举放在 `AppPage`，比赛状态枚举放在 `MatchPhase`，两者含义不同。主菜单“测试装备”复用配置选择页。英雄身份与外观暂缓，三套装备使用统一占位棋子。三种模式都有真实详情页面；联网匹配、创建/加入房间按钮根据尚未开放的状态禁用，不显示假的连接或排名。详见 [启动与模式选择 UI](./启动与模式选择UI.md)。

## 2. UI 文件职责

- `Game.uxml`：页面、控件、命名与层级。使用 UI Builder 可查看和调整布局。
- `Game.uss`：字体、颜色、尺寸、对齐、悬停和选中状态。相同角色卡、技能块用统一 class。
- `GameUI.cs`：`BindButton()` 绑定命名控件，`ShowPage()` 切换页面，`RefreshSelection()`、`RefreshMatch()`、`RefreshResults()` 显示状态。
- `AppController.cs`：按钮请求的具体应用行为，例如开局、暂停、重开。对局规则继续由 Core 执行。
- `RuntimePanel.asset`：UI 缩放配置，参考尺寸 1600×900。
- `ChineseFont.asset`：Noto 中文字体资产，可动态补充新字形；原始字体和 OFL 许可在 `Art/Fonts/`。

新增按钮时：先在 UXML 加入有意义的 `name`，再在 `GameUI.Bind()` 绑定，最后由 AppController 调用规则接口。不在 UXML 或按钮回调中直接修改比赛数据。修改现有控件名时，同步更新 `Q()` 查找和客户端检查脚本。

## 3. 选角页

三套测试装备点击后更新选中边框、生命、能量、武器与技能说明。训练为本人＋敌方远程靶标；对练为本人＋两名 AI 对抗三名 AI。说明可垂直滚动，开始按钮单独保留，不遮挡技能文字。当前装备是玩法实验，不绑定英雄与正式外观。

## 4. 比赛 HUD

| 位置 | 展示 | 数据来源 |
| --- | --- | --- |
| 顶部中间 | 青/橙比分、倒计时间、加时 | MatchState |
| 左上 | 训练或 AI 对练模式 | MatchMode / Overtime |
| 右上 | 暂停 | AppController |
| 顶部提示 | 持球提示、抢断结果、保护中等短反馈 | 状态 + MatchEvent |
| 球场中心 | 开球倒计时、进球提示 | MatchPhase |
| 底部左侧 | 本人装备、生命／能量条、护盾、球权／受控／复活 | PlayerState / BallState |
| 底部中间 | 右键、空格、Q、E 冷却，施放与能量不足反馈 | 配置 + PlayerState |
| 角色附近 | 统一棋子、武器轮廓、血条／能量条、瞄准、蓄力与恢复倒计时 | MatchView / PlayerView |

青队使用圆环与青色棋子，橙队使用菱形与橙色棋子。棋子由程序绘制，暂不确定英雄外观。足球保持高对比精灵和阴影；血条、能量条、近战扇区、弹体、保护罩与复活倒计时始终显示。关命中特效不隐藏判定信息。

0.13.1 球场视图铺满整个窗口，按实际窗口比例显示局部球场，镜头跟随角色。完整／精简 HUD 均叠在场景上，不留底部黑边；半透明技能栏、小地图和悬停说明按参考尺寸缩放。手机安全区和大字号仍需后续适配。

## 5. 输入和取消

| 操作 | 生效 |
| --- | --- |
| WASD | 对角线移动归一化，不额外加速 |
| 鼠标 | 世界位置经投影还原为逻辑瞄准方向 |
| 左键按下 | 必须当前持球才开始蓄力 |
| 左键松开 | 踢球；满蓄力额外保持 0.5 秒后自动踢出 |
| 右键 | 武器普攻，长按按间隔连续攻击 |
| C | 取消蓄力和未完成的普攻前摇 |
| 空格 | 沿当前瞄准方向启动通用抢断，方向锁定 |
| Q/E | Q 震荡弹，E 团队护盾／加速／治疗；按下即施放，不要求持球 |
| Esc | 暂停 / 恢复 |

短后摇、突进尾段及冷却结束前的按键最多缓冲 120 ms；快速点按保留松键，暂停、取消和受控清掉缓冲。

鼠标落在交互控件上时，左键、右键与 Q/E 不会发起球场操作；在控件上松开已有球场蓄力会取消。进入比赛或恢复后清除 UI 按钮焦点，避免空格同时触发按钮。暂停与失焦清空待消费输入边沿。

## 6. 训练工具

底部训练工具栏与快捷键执行同一接口，只有 `MatchMode.Training` 才允许生效：

- R：重置角色、自由球、技能物、冷却和临时状态，保留本次练习累计比分与统计。
- F：重置后把球交给本人，便于验证蓄力和持球技能。
- T：把球交给敌方靶标，把双方摆到适合尝试抢断的位置。
- 目标静止/移动：切换靶标的基础移动。
- F1：显示突进方向两侧的角度边界；接触结果显示实际角度。
- 结束训练：进入本次统计页。

训练模式不计时，HUD 中间显示“练习”。AI 对练不展示训练工具，规则接口也拒绝相应重置请求。

## 7. 后续 UI 工作

已经有完整的本地页面流转，可以继续增加新手分步教学、独立图鉴、按键重映射、技能目标预览和更完整的状态反馈。联机页、组队页、排位页和后台资料页应等真实服务可用后再接入，避免把占位状态当成实际功能。

后续每次 UI 调整至少检查：所有中文可见、选中状态明显、按钮能返回、暂停阻止时钟、冷却准确、训练工具在对练中不可用、球门附近没有 HUD 遮挡。客户端检查脚本会保存多个页面和 4:3 窗口截图，但精细交互与最终视觉仍需人工试玩。

## 8. 声音与反馈设置

全部按钮支持悬停/焦点与点击声；比赛动作声音由实际事件触发，失败技能仅提示不可用。三个音量滑块、静音和命中效果开关使用本机 PlayerPrefs 保存。蓄力有持续音、满蓄力提示、头顶进度和底部百分比。实现与复现见 [操作手感与音效](./操作手感与音效.md)。

## 9. 战斗验收

结算新增击倒／被击倒／伤害／治疗。倒地时 HUD 显示恢复中和 5 秒倒计时；满生命、满能量、清冷却在原地恢复。核心规则与后续打磨指标见 [合作乱斗玩法原型](./合作乱斗玩法原型.md)，真实客户端战斗检查及截图位于 `reports/runtime-combat-smoke/`。
