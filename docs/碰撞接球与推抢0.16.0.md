# 碰撞接球与推抢 0.16.0

> 后续修复：[持球碰撞夺球 0.16.1](持球碰撞夺球0.16.1.md) 补上敌方持球时的直接碰球夺球，并加入 0.25 秒接球保护和 80% 持球移速。本文保留 0.16.0 的历史实现与验收记录。

2026-10-12。用户明确这里沿用星际前锋的碰撞接球与推抢逻辑。此说明替换 0.15 中仍保留的“铲球命中直接转移球权”和低速自动接球设定；右键指令、体型碰撞、寻路和定位球继续保留。

| 场景 | 球权与足球行为 |
| --- | --- |
| 角色靠近自由球但碰撞体没有接触 | 球仍自由，没有接球距离判定 |
| 能行动的角色碰撞自由球 | 获得球权；普通球不设接球速度门槛 |
| 推队友 | 队友保留球权，球跟随队友一同位移 |
| 从正面或侧面推持球敌人 | 人被推开，球以零速度留在原位置，成为自由球 |
| 从背后推持球敌人 | 敌人保留球权，球随敌人位移 |
| 推开敌人后自己仍未碰到球 | 不会获得球权；其他球员也能先碰到自由球 |
| 眩晕、推移或倒地中的角色 | 不能接收自由球；被推的原持球者不会在位移中立刻捡回刚落下的球 |

接球检查两个圆的实际接触，包括连续路径上的首次相交与已发生的表面接触。角色圈与球圈之外没有额外吸附区域；高速球接触仍接球，停在球附近不会接球。高球保留既有专用技能高度规则，普通球仍是二维。普通比赛的球权只从碰撞入口产生，F/T 训练配球和定位球指定主罚者是明确的准备工具。

推不是直接抢球技能。实际身体接触后推开第一名角色，同队身体也能被推。正面／侧面推敌人时，保持足球在接触前所在的位置，不把球挪到原持球者中心或推者脚下，也不向球施加推力。足球随后通过普通碰撞流程被任何合格角色拾取；若推者当时已经碰到这个球，可以立即经真实接触获得球权，但推本身不会赋予球权。

背后判定使用持球者朝向与实际接触位置：当前背后左右各 45° 的扇区内保留带球，正面与侧面释放足球。45° 是可调原型值，包含边界。判断与推者鼠标朝向无关；调试显示改为持球者的背后扇区。队友不受这个落球角度限制，始终带球位移。完整保护和重复控制保护继续阻止无效位移。

炸弹击退采用同样的角度与球权处理，方向来自爆心；不改动炸弹现有的敌方过滤、眩晕、范围或费用。AI 会从侧面靠近持球敌人，推开后追踪留在原地的自由球，不靠命中自动夺球。实际碰撞接收到因敌方推而释放的球才统计一次“碰撞夺球”。

操作仍是右键地面移动、右键敌人追击攻击、右键队友跟随、右键足球追球；Shift 追加，S/H 停止，空格推，左键踢球，Q/E/G 保留。右键追球只发移动指令，不会直接授予球权。角球、任意球和出界规则继续有效，点球不加入。
