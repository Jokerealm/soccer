# 界面布阵与 AI 配合 0.31.0

- 连接游戏帐号的帐号、密码、游戏名改为深色输入区和明亮文字，密码继续遮罩。组队大厅的准备、普通匹配、排位等按钮分别设置可用和禁用状态的清晰配色；房间号也使用深色输入区。
- 首页和模式菜单保留上下选择，Enter 统一用于聊天，鼠标点击进入菜单。聊天输入时上下键不会改变菜单选择；同一帧的 UI 和键盘事件只处理一次 Enter。
- 选角页点击武器、Q、E 各自的卡片，独立展开或收起参数和完整介绍，可同时展开多个。更换角色时重置展开状态，布阵刷新不会打断阅读。
- 每队六个镜像固定点：门前、左后、右后、中前、左前、右前。三名球员保留选位自由，不能占同一点。点击图上的点或下方位置按钮选择；超时 AI 从空闲点中补选。服务器与客户端使用同一套点位校验。
- 根据本地玩家的队伍绘制血条：己方绿色、敌方红色，青队和橙队视角均适用；低血量不改变敌我色，能量条仍为蓝色。
- AI 在清晰射门、传球和带球之间做选择。判断传球线路、队友空间、向前推进、受压和资源状态；蓄力期间继续跟踪接球者，接球队友倒地或线路被截断时取消传球。两名无球队友分路接应，传球者不会马上跟队友争抢刚踢出的球。球童保留简单判断，球员使用短距离预判，球神与作弊者使用更远的接球预判和射门选线。

Steam 好友指 Steam 原生房间邀请，独立于游戏帐号好友。已保留游戏运行时接受邀请，并补齐游戏尚未运行时 `+connect_lobby` 启动加入流程；未来从 Steam 库启动时读取 Steam 提供的 AppID，并自动进入 Steam 身份。首次设置游戏名后继续加入受邀房间。

游戏目前尚未在 Steam 发布，试玩仍使用测试 AppID 480。正式发行需要在 Steamworks 配置实际 AppID、发行包与启动项，并从正式 depot 排除开发用 `steam_appid.txt`。不能把当前测试 AppID 当作已发布的商店应用。[邀请接口与启动参数](https://partner.steamgames.com/doc/api/ISteamMatchmaking#InviteUserToLobby)。

本版协议为 `SkillSoccer/0.31.0/11`，联机双方和游戏服务需要一起更新到本版。本机继续作为服务器，地址为 `http://192.168.31.29:27862`，帐号和好友数据保留。

验证记录在 `reports/refinement-031-*`。Windows x64 由团结构建；界面和游戏流程使用 macOS 原生客户端验证，尚未进行 Windows 实机验收。
