相较 GitHub 上一个试玩版 0.26.0，本版合并发布 0.27–0.30 的完整改动。

新增与改进：

- 滚轮缩放比赛视野，左右 Ctrl＋滚轮旋转视角；资源条和世界文字保持朝向镜头。
- 按住中键或 Alt 打开五向信号托盘，移动选择、松开发送；信号显示在场上和小地图。
- 开场六边形站位与空气墙，允许右键热身移动，开球后解除；AI 增加球童、球员、球神、作弊者四档。
- 小地图点击观察，Ctrl＋1–9 编队，双击数字跟随；观察不改变操控角色。
- Steam／游戏好友分栏，独立游戏帐号注册，好友搜索与申请、在线状态、私聊；支持队伍、房间、队内和全场聊天。
- 最多三人组队，整队开房、普通匹配和排位；六名真人匹配，服务器执行比赛并结算排位分。
- 游戏名字与房间界面更新，修复未加入前的 Steam 房间搜索／房主校验问题。

试玩方式：

完整解压 `SkillSoccer-0.30.0-Windows-x64.zip`，运行 `SkillSoccer.exe`。可使用 Steam 或离线进入，Steam 目前仍为开发测试 AppID 480。

客户端预设开发机的临时游戏服务 `http://192.168.31.29:27862`，只适用于同一局域网，**不是可在公网访问的服务**。同网玩家可注册独立游戏帐号，使用好友、聊天、组队及匹配。地址可在 `SkillSoccer_Data/StreamingAssets/game-service.json` 修改，或用 `--soccer-auth-url` 覆盖。Steam 原生房间／邀请、训练与 AI 对练继续可用。普通匹配与排位需六名真人，好友房间可以手动补 AI。

`SkillSoccer-0.30.0-Server.zip` 是不含玩家存档和密钥的独立服务包，需要 ASP.NET Core Runtime 10。部署与存档说明见包内文档及 [server/DEPLOY.md](https://github.com/Jokerealm/soccer/blob/v0.30.0/server/DEPLOY.md)。

验证：核心 255 项、网络 58 项、视角／信号专项 58 项、完整客户端回归 613 项通过；六名独立帐号的普通／排位、实际进球与排位结算流程通过。macOS／Windows 构建均为零错误、零警告。

验证边界：Windows 为 macOS 上交叉构建，尚未实机运行本版；未把本机连通验证等同于其他物理电脑或公网验证。正式 Steam Web API 凭据、真实好友邀请及公网／SDR 路由不在本次验证范围。联机协议为 `SkillSoccer/0.29.0/10`，推荐使用本次新版。
