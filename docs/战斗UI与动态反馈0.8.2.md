# 战斗 UI 与动态反馈 0.8.2

针对头像、技能图标和血量条质感不足、静态反馈缺乏连贯性的问题，本轮重新制作美术并接入实际客户端。

## 统一美术

2 张临时头像和 9 张技能／武器插画，使用内置 imagegen 分别生成。统一深青黑底色、象牙白装甲、青绿能量和暖金高光，与球场配色协调。原稿为 1254×1254，保留在 `assets/original/ui/battle-v2/`；提示词完整保存在 [generation-prompts.json](../assets/original/ui/battle-v2/generation-prompts.json)。游戏直接使用独立 PNG，旧版 SVG 图标保留作历史源稿。

头像使用圆形装甲边框，技能使用内凹方形框、按键角标和插画；底栏采用倒角面板、细高光和统一分隔线，顶部比分、暂停与训练工具沿用同一组配色。生命和能量条加入亮暗材质、刻度与清晰的当前／上限数值。

头像仍是可替换的临时内容，未确定最终英雄外观。头像与当前模型用轻装／重装、头盔与双炮区分角色，后续可以接入用户的无厘头角色设定。

## 动画与反馈

| 时机 | 展示反馈 |
| --- | --- |
| 页面切换／进入球场 | 页面约 0.28 秒淡入，底栏约 0.48 秒滑入 |
| 鼠标悬停技能 | 图标框轻微放大与边缘提亮 |
| 技能、踢球、铲球或普攻触发 | 图标弹动、扫光、短寿命 UI 火花，配合既有操作音效 |
| 技能冷却 | 放射形遮罩和数字同时读取真实剩余冷却 |
| 冷却完成 | 金色扫光与火花，踢球就绪也补入提示音 |
| 生命／能量消耗 | 数值立刻准确更新，填充条平滑变化，背景缓降条显示损失，消耗数字短暂浮出 |
| 受击 | 头像红色脉冲、边缘轻微红晕、受伤提示和场内命中火花 |
| 低于或等于 30 生命 | 头像边框缓慢红色呼吸、生命填充变红 |
| 接到球 | 头像暖金提示与少量光点 |
| 击倒、眩晕、复活与进球 | 分别显示提示；复活和进球产生短暂光点 |
| 爆炸 | 爆炸位置散出暖金火花，配合既有范围环和音效 |
| 关闭命中反馈 | 清空 UI／场内粒子与动作脉冲；数值与必要状态继续显示 |

动画只影响显示。生命／能量、冷却、移动、碰撞、原地复活时间及二维球规则均未改变。缓降条不替代真实血量，技能冷却仍按实际 6 秒／5 秒及各角色 Q/E 计时。

UI 粒子固定池最多 80 个，场内粒子固定池最多 256 个。按动作触发短寿命粒子，不在场上持续铺粒子；返回首页、重置训练或关闭反馈会清理。

## 验证与演示

108 项 macOS 实际客户端检查全部通过。两平台最终构建成功，构建摘要均为 0 错误、0 警告；最终客户端日志没有此前 UI 缩放警告。完整结果见 `reports/ui-082-validation.json`；实际客户端截图和 48 帧动态采样位于 `reports/runtime-ui-082-final/`。

macOS 客户端验证和两平台构建分别记录；Windows 实机运行、真人操作的主观手感仍未验证。游戏玩法代码未改变，沿用 0.8 的 119 项核心检查结果。
