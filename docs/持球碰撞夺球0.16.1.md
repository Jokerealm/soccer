# 持球碰撞夺球 0.16.1

2026-10-12。根据 Windows 试玩反馈，修复“敌方持球时碰球不能夺球，只能先按空格”的问题。用户提供的《星际前锋：地图文件与 Unity 复刻参考》是静态解包参考，文中的实现建议作为资料，不替代当前项目的操作和玩法要求。

## 本次修改

之前 `BallSystem.Step` 在有持球者时只更新脚前球并返回，碰撞接球只处理自由球；`UpdateHeldBall` 还会将受阻足球自动挪到可用侧面。两者叠加，使敌方脚前球难以被真实碰撞夺走。

现在自由球与敌方脚前球都通过同一个实际碰撞入口获得球权。持球时检查敌人的真实接触、角色与球的相对平移路径，按最早接触选择唯一接球者；不扫掠转身时穿过持球者身体的弦线。球在角色接触面保持可碰撞，不再自动侧移躲开来抢球的人。没有额外吸附范围，碰到敌人身体但够不到脚前球仍不会夺球。

| 情况 | 当前行为 |
| --- | --- |
| 接触敌方脚前球 | 接球保护已结束时直接夺球；无需空格，不扣生命，不触发铲球冷却 |
| 右键敌方足球 | 持续追球；实际接触后获得球权 |
| 右键敌方角色 | 保留追击武器攻击；抢球时应点足球或走向脚前球 |
| 普通队友碰持球队友的球 | 保留原队友球权 |
| 刚接到球 | 0.25 秒内禁止自动碰撞再次易手；同一物理子步只发生一次转移 |
| 推开敌人后落球 | 立即清除接球保护，任何合格角色可通过实际碰撞接球 |
| 完整保护中的持球者 | 阻止直接碰撞夺球 |
| 倒地、眩晕、推移、刚复活的接球者 | 不可碰撞接球 |

推仍用于腾出空间，不直接分配球权。队友／背后受推时带球位移；敌方正面／侧面受推后球留原地。直接碰撞夺球和拾取敌方被推落的球都计一次夺球，并更新最后触球人，保证后续出界归属正确。AI 优先靠近足球，也可使用推击制造空间。

## 采用的解包参考

- `HoldingtheBall` 移速倍率 0.8：持球速度改为基础速度的 **80%**，蓄力时继续叠加已有蓄力减速。
- 接球后的 `Untakable` 为 0.25 游戏秒：新增独立 `PossessionContactLock`，在当前模拟时钟下使用 **0.25 秒**；踢球者的自接限制独立保留。踢出、高球技能释放、推落、倒地掉球、重置和定位球准备清除该球权保护。
- 队友自动拾取过滤和角色状态过滤：接球入口统一校验，球权只由 Core 决定。

SC2 的游戏速度和地图距离尚未实测校准，本轮只采用上述无量纲倍率与可调保护窗口。原脚本的力变量没有直接当成 Unity 米／秒；资料中的球路离散公式、各档推击费用、6 游戏秒推冷却、方向 ±30°、正式加时流程与 42 角色技能仍作为后续对照。当前已确认的按键、6／5 秒冷却、二维常规球路和队友／背后推球规则继续以项目设计为准。
