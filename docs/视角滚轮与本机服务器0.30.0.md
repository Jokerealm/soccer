# 视角滚轮与本机服务器 0.30.0

2026-10-15。保留聊天、好友、组队与权威匹配，新增比赛镜头操作，并将当前 Mac 配置为暂用的游戏服务器。

## 比赛操作

- 鼠标滚轮：向上拉近、向下拉远；近景和远景均有限制。
- 按住左／右 Ctrl 再滚动：绕球场水平旋转视角，不改变缩放。可以连续旋转一周。
- 按住鼠标中键或 Alt：打开同一个快捷信号托盘，移动鼠标选择方向，松开发送。中央区域或 Esc 取消；同一手势只发一次，仍有发送冷却。中键为固定入口，Alt 对应的键盘快捷键可在设置中修改。
- 小地图点击观察、Ctrl＋1–9 编队、双击数字观察及反引号键回到自己继续保留。

滚轮只在比赛中、鼠标位于球场且未打开聊天／暂停／信号托盘时作用于世界镜头。选人界面的滚轮仍用于模型预览。观察队友、回到自己、同场训练重置及进球不会清除手动缩放和旋转；新比赛恢复默认视角。镜头旋转后，资源条和状态／伤害文字仍朝向镜头，鼠标选中与地面射线使用当前镜头。

## 当前服务器

已在当前 Mac 启动 0.30.0 游戏服务：

```text
http://192.168.31.29:27862
```

服务监听所有本机 IPv4 接口。当前客户端内置上述局域网地址，Windows 解压后可直接注册游戏帐号、添加好友、聊天、组队、开房和排队。服务仍要求普通匹配／排位凑齐六名真人；好友房间可以补 AI。生产配置不开放旧的 a/a、b/b 调试帐号，请创建独立游戏帐号。

同一局域网的其他电脑可以连接；这不是已部署的公网服务，没有配置公网域名、HTTPS 或路由器端口映射。当前 Mac 须开机、保持登录并可被局域网访问。Steam 原生房间与邀请继续独立可用；Steam 游戏社交票据尚未配置 Web API Key 时，可在游戏好友页连接独立游戏帐号。

服务由当前用户的 LaunchAgent `com.skillsoccer.local-server` 管理，登录后自动启动、进程异常退出后重启。程序及帐号／好友／聊天存档位于 `~/Library/Application Support/SkillSoccer/Server/`，日志位于 `~/Library/Logs/SkillSoccer/server.log`。升级程序保留数据，未把玩家存档和密钥放进试玩包。

在仓库中管理：

```sh
tools/python tools/local_server.py status
tools/python tools/local_server.py stop
tools/python tools/local_server.py start
tools/python tools/local_server.py uninstall
```

`stop` 停止当前服务；`uninstall` 同时取消登录自启，保留存档。更新服务或本机 IP 后可运行 `tools/python tools/local_server.py install`。客户端的 `StreamingAssets/game-service.json` 可直接编辑地址，无须重新编译；启动参数 `--soccer-auth-url` 优先于此文件，此文件优先于旧的本机设置。Windows 文件位置为 `SkillSoccer_Data/StreamingAssets/game-service.json`。

0.30 的镜头与输入变更没有更改联机数据格式，继续使用 `SkillSoccer/0.29.0/10`。测试使用独立的临时帐号与存档；实际本机服务通过回环和局域网地址检查。Windows 当前为跨平台构建产物，仍需 Windows 实机验收；未把本机连接检查等同于其他电脑或公网实测。
