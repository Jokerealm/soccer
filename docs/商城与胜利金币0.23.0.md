# 商城、胜利金币与菜单导航 0.23.0

首页新增“商城”和金币余额。商城包含英雄、皮肤分类：枪兵与雷神为初始英雄，均已拥有；皮肤分类暂时展示即将上线。英雄定价、购买、皮肤装备和新英雄解锁将在后续接入，当前可先通过胜利积累金币。

## 胜利奖励

AI 对练、局域网和互联网正式对局中，本地玩家所在队伍胜利获得 **100 金币**。失败、平局、退出、训练场和新手教程不发金币。比赛结束后结算页显示胜利奖励和余额，回到首页／商城立即更新。

同一比赛只领取一次；再次打开结算、重复收到最终网络快照、返回主菜单均不重复发币。联机根据房主最终比分与本地玩家实际队伍判断胜负，客人也能领取获胜奖励。每次重新开局都有新的奖励编号。

金币以本机存档保存，关闭客户端后仍保留。离线玩家、帐号 a、帐号 b 使用各自余额，登录不会复制离线金币。当前没有云端同步，Mac 与 Windows 的余额独立。存档格式已包含余额和比赛奖励记录，未来正式经济系统需要由服务器管理奖励、购买和拥有的物品。

保存时先完成临时文件写入与替换，再更新内存余额；保存失败不会假装已获得金币，存档读取失败也不会把旧存档覆盖成零。

## 方向键导航

首页五项入口支持上下循环选择与 Enter 确认，模式选择页同样支持方向键。鼠标点击继续可用。选中入口会显示金色边线和高亮。

旧首页只注册普通键盘事件；本次同时处理 UI Toolkit 导航事件，并在首页／模式页采样实际键盘输入，处理焦点落在根节点时的操作。来自同一按键的两种事件在同一帧只执行一次，不影响比赛、登录输入框或设置中的按键捕获。

规则测试覆盖胜方队伍、同局去重、失败／平局／练习限制、保存失败回滚、重载和余额溢出。真实客户端验证导航事件、键盘采样、商城切换、实际文件保存重载、帐号隔离、胜利与其他结果；双客户端验证获胜客人的结算与最终快照去重。1024×768、1280×720、1920×1080 检查首页五项入口和商城布局。
