# 联机发现与操作优化 0.18.0

2026-10-12。修复局域网发现并调整启动、操作、移速与生命恢复。

## 启动先选择登录或离线

资源加载完成后先显示登录页。联网登录会向填写的服务地址请求 `/api/login`，只有服务验证成功才进入在线模式；仍可使用公开调试帐号 a/a、b/b。登录失败或服务器不可用时可直接选择“离线进入”，继续训练、AI 对练和局域网房间。首页可切换帐号／重新联网登录；离线模式的互联网入口禁用，局域网无需任何帐号服务。

登录服务源码和启动／部署步骤见 [登录服务说明](https://github.com/Jokerealm/soccer/blob/main/server/README.md)。当前没有部署公共登录地址，请填写自己的服务地址或离线进入。房间密码仍是单独的入房口令。

## 局域网发现

旧版只向通用广播地址和本机环回发送查询，在多网卡、VPN 与部分 Wi-Fi 路由下容易选择错误接口。新版枚举活动 IPv4 网卡，计算每个网卡的实际子网广播，同时使用局域网组播查询、房主每秒通告和主动查询回复。根据房间唯一 ID 去重，并优先展示非环回地址；房主退出后约五秒清除发现记录。

两端都使用 **0.18.0**，连接同一允许设备互访的局域网。房主选择“离线进入 → 普通模式 → 局域网 → 创建房间”；客人在相同入口选择加入，等待自动发现，也可点击刷新。发现与通告使用 UDP **27861**，实际比赛默认 TCP **27860**。Windows 防火墙需放行这些端口；访客 Wi-Fi、AP 隔离和阻止广播／组播的网络仍会影响自动发现，可使用房主的局域网 IP:端口直接加入。

自动发现端口不可用时仍保留地址直连。上述排查依据当前代码及本机多进程验证，Windows／Mac 两台物理设备的网络环境仍需复核。

## 操作

| 按键 | 功能 |
| --- | --- |
| 右键 | 移动、追击敌人、跟随队友或追球；不绘制移动路径 |
| Shift + 右键 | 追加移动指令 |
| V 按住／松开 | 蓄力／踢球；鼠标决定方向 |
| 空格 | 推击／铲球 |
| 左键 | 确认已经选中的技能目标；普通左键不会踢球 |
| E（雷神） | 进入方向选择，再左键确认辅助推进器；按 E 再次取消选择 |
| E（枪兵） | 脚下／足球上放置炸弹，按原规则立即执行 |
| Q / G | 角色技能／枪兵提前引爆 |
| C | 取消蓄力、目标选择与当前指令 |
| S / H | 停止移动 |
| Esc | 单机暂停／联机本机菜单 |

右键寻路和绕开单位仍会执行，但不显示路径线。足球轨迹只在 V 蓄力时显示。技能目标选择的预览与踢球蓄力互相独立，点击界面控件不会确认球场技能。

## 移速与生命恢复

用户提供的《星际前锋：地图文件与 Unity 复刻参考》第 3 节明确写有多数单位生命上限 100、生命回复 **2**；第 5 节列出常见原始速度 2.3515／2.0，并指出游戏时间需要结合 Faster 速度校准。

本原型保留枪兵 2.35、雷神 2.0 的角色相对速度，统一增加可调的 **1.6 倍**移动倍率，实际基础速度变为 3.76／3.2。持球仍乘 0.8，蓄力、技能加速和寻路停步使用一致的实际速度。倍率是针对当前球场与现实秒手感的原型调整，不代表完成原地图时间尺度校准。

存活球员在比赛进行中每模拟秒恢复 **2 点生命**，不超过 100，不记为支援治疗；倒地时不靠恢复复活，仍执行五秒原地满状态复活。单机暂停和非比赛阶段不会继续自然恢复。权威房主恢复后同步实际生命值给客户端。

验证汇总见 `reports/usability-018-validation.json`。Windows 包：[0.18.0 试玩发布页](https://github.com/Jokerealm/soccer/releases/tag/v0.18.0)。
