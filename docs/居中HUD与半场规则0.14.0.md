# 居中 HUD 与半场规则 0.14.0

2026-10-11。头像与技能栏整体居中，技能冷却显示真实灰度图标、顺时针一圈进度与剩余秒数；球场角色头顶收为半透明生命／能量双条。最初的 [游戏设计文档](游戏设计文档.md) 已汇总目前要求，旧稿保留历史副本；[确认单](关键设计确认单.md) 与 [UI 说明](UI界面与交互说明.md) 同步更新。

## 界面

- 全宽居中锚点负责布局，入场动画只移动面板本身，防止过渡覆盖水平居中。雷神隐藏 G 后缩小技能区域，两角都整体居中。
- 原高清图标生成实际灰度变体，保留尺寸和透明通道。工具为 tools/prepare_cooldown_icons.py，来源与校验记录 assets/cooldown-icon-provenance.json。
- 环形进度从顶部顺时针增加，读真实冷却比例；刚好完成一圈时恢复彩色、清空剩余时间，整环短暂亮起。未就绪时向上取整到 0.1 秒；暂停冻结信息进度。
- 场上资源是单一动态圆角网格，上绿生命、下蓝能量；小侧标区分敌我和本人。保留短生命损失残影与低生命变色，删除头顶弹药、蓄力和 YOU，倒地仍显示恢复时间。
- 完整／精简切换、低生命屏幕红边、悬停说明、头像小地图、全屏球场与足球反馈保留。

## 半场

用户要求比赛分上下半场。当前原型沿用总有效时间 5 分钟，每半场 150 秒；中场 2 秒重新开球，橙队开球，比分保留。平局最多 90 秒金球加时。时长、中场休息、换边和娱乐规则仍可调，当前不换球门。

Core 保留总剩余与累计有效时间，UI 显示当前半场时间。上半场结束不会按比分直接结算或误触加时；压哨进球先庆祝再转半场。倒地者不提前复活、不移位，继续实际 5 秒恢复。训练不触发半场。
