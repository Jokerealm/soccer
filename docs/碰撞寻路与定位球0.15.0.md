# 碰撞、右键寻路与定位球 0.15.0

> 球权规则已在 [0.16](碰撞接球与推抢0.16.0.md) 按用户补充订正；本页保留 0.15 当时的实现记录。

2026-10-12。用户要求角色与角色碰撞、让体型参与玩法、足球有体积；操作与寻路参考星际争霸，持球／推抢沿用项目的星际足球参考；加入整球出界、角球、任意球，点球暂不做。用户再次明确这是暴力足球，允许进攻。因此武器、技能和推抢均保持合法，任意球用于定位球二次触球违例，不因战斗停哨。

## 操作

| 指令 | 行为 |
| --- | --- |
| 右键地面 | 一次点击持续移动，到达后停止；自动绕开友敌身体、球门柱和生效护墙 |
| 右键敌方球员 | 有武器时追击目标，进入射程持续开火；离开射程继续追击；目标倒地后取消 |
| 右键队友 | 持续跟随，保持身体间距；无武器者右键敌人同样跟随 |
| 右键足球 | 追球，到可接距离自动获得球权 |
| Shift＋右键 | 最多追加 16 条路线／跟随／追击指令 |
| S／H | 停止当前指令，清空队列 |
| 左键按住／松开 | 鼠标瞄准，蓄力／踢球，成功出球后 6 秒冷却 |
| 空格 | 朝鼠标方向推抢，5 秒冷却，扣生命，接触后按原有 45° 原型判抢断或推移 |
| Q／E，枪兵 G | 保留原有角色技能与引爆 |
| C | 取消蓄力、未提交动作和移动／追击指令 |
| F2／F3 | 训练角球／任意球；工具栏有同名按钮 |

WASD 不再用于原生玩家移动，S 改为星际式停止。按钮和技能栏点击不会透传为球场指令；热身只接收移动，暂停、失焦、重置、倒地与重开清除指令和队列。

## 体型与球权

枪兵半径 0.5 u，雷神半径 0.8 u，足球半径 0.27 u。足球逻辑半径与三维模型缩放、离地高度和滚动周长统一使用规则参数。友敌身体都阻挡普通走路、推移和突进；连续圆扫掠避免高速穿越，普通走路沿接触面滑动，突进在首次接触结束。重叠按圆面积分担修正，大体型更难被挤动。倒地角色不阻挡，原地复活后恢复碰撞。

路径使用按角色半径扩张障碍的圆形可见图 A*，约每 0.2 秒或路线新被阻挡时重算，再由局部连续扫掠执行。尺寸更大的角色不能通过小角色能穿过的狭窄通道。热身防护罩和定位球距离也参与绕行与阻挡。此实现借鉴星际的操作与避障行为，并非原作内部算法的移植。

持球沿用脚前随行与低速自动接球、高速挡球的星际足球参考。接触对手身体、球门柱时球不会穿过去；前方没有空间时球护在可用侧面。抢断须实际接触，仍使用现有 45° 判定和重复控制／夺球保护；两角色推力、持球减速、技能、冷却与生命消耗保留。

## 出界与定位球

球的一部分压线或越线仍算场内，球体完整越过线才判出界。记录最后触球者，包括接球、踢球、抢断和身体反弹；该记录与传球者分开。连续路径按首次越过的边线裁定，门柱仍反弹。普通球和技能高球的出界均使用平面投影。

| 情况 | 判定 |
| --- | --- |
| 整球越边线 | 最后触球方的对手主罚界外球，地点对应越线位置 |
| 整球越底线且守方最后触球，未进球 | 攻方角球，选择出界侧的角球点 |
| 整球越底线且攻方最后触球，未进球 | 守方球门球 |
| 整球越有效门线 | 正常进球优先，只计一次 |
| 定位球主罚者在其他人触球前再次触球 | 对方在违例地点主罚任意球；禁区内也不改为点球 |
| 角球、任意球直接进对方门 | 可计分 |
| 界外球直接进对方门 | 球门球 |
| 定位球直接踢进本方门 | 对方角球 |

定位球按获球方最近的存活角色分配主罚；全队倒地时等待真实复活，不提前恢复。足球固定，准备 1 秒，对手退出 3 u 加自身半径的范围；主罚角色左键瞄准／蓄力／踢出，AI 自动主罚。有效比赛时间暂停至出球，生命和技能冷却不会整队刷新。公共踢球冷却不能阻止主罚，出球后重新开始 6 秒冷却。镜头展示球与主罚点，场上显示距离圈，顶部标明类型、主罚队和当前操作。

界外球当前复用脚下踢出的操作与动画，没有手抛动作；距离和准备时长是适配本游戏 56×34 球场的可调原型值，不是完整职业足球规则实现。

## 来源和开发入口

角色设定仍来自用户的星际足球表格，见 `reports/star-strikers-source.json`。右键地面移动／对敌攻击参考暴雪的 [简化操作指南](https://news.blizzard.com/en-us/article/6640645/game-guide-simplified-controls)，Shift 队列参考 [特殊操作指南](https://news.blizzard.com/en-us/article/4552955/game-guide-special-control)。整球越线、角球归属和二次触球参考 IFAB 的 [出界规则](https://www.theifab.com/laws/latest/the-ball-in-and-out-of-play/)、[角球规则](https://www.theifab.com/laws/latest/the-corner-kick/) 与 [任意球规则](https://theifab.com/laws/latest/free-kicks/)，进攻合法性按用户的暴力足球设定调整。

- `Core/MovementSystem.cs`：所有角色的扫掠、滑动和分离。
- `Core/NavigationSystem.cs`、`ContextOrder.cs`：路径、持续指令与右键上下文。
- `Core/BallSystem.cs`：球体、移动身体相对扫掠、持球和越线。
- `Core/RestartSystem.cs`：出界恢复、主罚分配、保护距离和任意球违例。
- `Runtime/Input/KeyboardMouseInput.cs`：原生右键命中、Shift 队列与停止。
- `Runtime/UI/GameUI.cs`、`UI/Game.uxml`：定位球提示和训练按钮。
- `Runtime/Presentation/MatchView.cs`：目标圈、调试路线和定位球距离圈。

验证结果汇总于 `reports/collision-rts-015-validation.json`；Core 原有与新增规则报告在 `reports/collision-rts-015-core/core-tests.json`，实际 macOS 客户端报告与截图在 `reports/runtime-collision-rts-015-final/`。Windows 构建可交付，Windows 实机操作手感需在该平台试玩。

最终验证：171 项 Core 测试、306 项 macOS 客户端检查全通过；macOS 与 Windows 构建均 0 错误、0 警告。额外 OS 级鼠标自动化遇到 CUA 应用绑定错误，未宣称通过实体键鼠验收；当前工程仍可直接试玩。
