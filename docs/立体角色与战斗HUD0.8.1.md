# 立体角色与战斗 HUD 0.8.1

用户提供的 `default.jpg` 展示了俯视透视下的立体角色、足球，以及底部集中排列的技能、生命和能量。本轮把这个方向接入实际游戏，照片只作展示参考，未作为游戏贴图使用。

## 场上角色

枪兵使用轻装人形、头盔和脉冲步枪；雷神使用较宽的机甲轮廓、厚装甲和双炮。这些是为了测试玩法辨识度而制作的临时造型，最终外观、无厘头角色风格和角色设定仍由后续设定决定。

模型由真实网格组成，装甲具有倒角，头盔和关节有曲面。所有部件使用 Standard 光照材质，接收场内灯光和阴影，并向地面投射阴影；队伍颜色用于装甲，脚下圆环／菱形继续辅助区分阵营。走路摆腿、武器后坐、受击挤压和眩晕摇晃只影响显示网格，不改变移动或碰撞规则。

足球继续使用既有的 32 块球面网格、凹缝与滚动旋转，和角色共享场景光照。普通踢球、铲球、突进、射门及球门判断依然只使用二维规则；模型高度仅用于显示，未来指定的越顶技能才启用球的高度。

## 战斗底栏

- 左侧：临时角色头像、角色名字、持球／眩晕／原地复活状态。
- 中间：Q、E 角色技能；枪兵额外显示 G 引爆。随后是左键踢球、空格铲球和右键普攻。
- 每个技能使用方形图标、按键角标、技能名和消耗提示。冷却中显示数字和递减的遮罩，缺生命或缺能量时明确提示，触发和拒绝操作有边框反馈。
- 炸弹存在时显示爆炸倒计时，G 图标高亮；G 提前引爆不与 E 冷却混用。
- 技能下方是整行生命与能量条，始终显示当前／上限。按住左键时另外显示蓄力条。
- 上方显示当前移速和推力，右侧保留移动、瞄准、蓄力与取消的简短提示。悬停技能可以查看完整说明。

11 个原创图标保留可编辑 SVG，游戏导入 768×768 PNG。来源和重建方式见 `assets/battle-hud-provenance.json` 与 `tools/create_battle_hud_icons.cjs`。

## 玩法数值

继续沿用 0.8：两种角色均为 100 生命、100 能量，击倒后原地 5 秒满状态恢复；左键踢球冷却 6 秒，空格铲球冷却 5 秒，铲球扣血使用原型公式 `10 / 推力`。Q/E、普攻、炸弹和突进的数值均未调整，详见 [枪兵与雷神玩法原型 0.8](枪兵与雷神玩法原型0.8.md)。

## 实机验证

macOS 实际客户端的 99 项检查全部通过。macOS、Windows 两个最终构建均成功，构建摘要为 0 错误、0 警告。玩法代码与数值未改动，沿用 0.8 的 119 项核心检查结果；本轮新增验证集中在角色网格、光影、技能 HUD 和窗口布局。完整结果见 `reports/visual-081-validation.json`。实际客户端截图保存在 `reports/runtime-visual-081-release/`，包含训练 HUD、同时冷却、炸弹、雷神、3v3、4:3 比例和角色／足球放大画面。

Windows 构建与 Windows 实机运行分开记录；自动检查不代表已经验证真人操作的主观手感。角色造型也仍属于可替换的玩法原型。
