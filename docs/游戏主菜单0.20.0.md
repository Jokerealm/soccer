# 游戏主菜单 0.20.0

主页改为实际球场与游戏角色的实时三维展示。枪兵、雷神和足球使用对局里的模型、材质、灯光与投影；菜单角色有轻微待机动作。进入比赛后切回原有比赛相机，菜单角色不参与对局。

左侧入口只有四个：

- **开始比赛**：本地 3v3 AI 对练，直接选择角色并开始。
- **联机对战**：选择互联网或局域网，然后创建或加入房间。
- **训练场**：选择角色，练习移动、传射和技能。
- **设置**：调整声音、命中反馈与完整技能栏。

方向键上下选择，Enter 确认，也可以使用鼠标。移除首页的宣传口号、粉彩大卡片、未开放的排位／娱乐模式入口、重复的“乐子打法”入口。加载页也删除口号，角色选择的开始按钮改为直接的“开始比赛”／“开始训练”。

离线进入后默认选中局域网，互联网选项需联网登录。联机页直接提供登录入口；创建、加入与房间大厅继续保留上一版的简洁表单、六位房间号、可选密码、自动端口。

设计参考只用于入口组织与视觉层级，没有使用参考游戏的素材：

- [Rocket League 官方 Play Menu 设计说明](https://www.rocketleague.com/news/first-look-play-menu-changes-coming-to-rocket-league)：把训练、离线比赛、私人比赛归入明确的游玩入口。
- [Halo Infinite 官方菜单调整](https://support.halowaypoint.com/hc/en-us/articles/15218713612564-Halo-Infinite-Update-May-10-2023)：自定义比赛入口直接提供浏览房间与创建比赛。

角色造型仍是现有可替换的原型模型。联网协议与比赛数值沿用 0.19.1；公共互联网登录服务、目录和中继尚未部署。
