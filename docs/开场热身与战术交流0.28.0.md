# 开场热身、AI 难度与战术交流 0.28.0

2026-10-15。攻击与击倒用于创造进球机会：对手过度使用技能会消耗生命或能量，可以趁资源不足时攻击、击倒、抢球。本次保留既定的生命／能量消耗、5 秒原地复活、6 秒踢球与 5 秒推抢冷却。

## 开场六边形与空气墙

初始布阵的每个位置有本队颜色的六边形地面标志。初始倒计时期间，球员可以在自己的六边形内连续右键走动、Shift 追加指令和停止，整个人物的碰撞体都不能越过空气墙；足球中圈防护罩继续保留。开球后六边形标志和空气墙同时解除，保留热身结束时的位置，清除热身中尚未完成的移动指令，避免自动跑向之前误点的远处。

六边形外接圆半径暂为 2.2 个球场单位，可在 `MatchRules.OpeningHexRadius` 调整，显示与判定读取同一参数。仅初次开球启用，不改变进球后重开的既定规则。

## 四档机器人

开始游戏页选择本地 AI 难度并保存；联机房间由房主统一选择机器人难度，全员可见。更改会取消准备与开场倒计时，需要重新准备。难度随选人和比赛开局同步，断线接管也使用本房间的难度。

| 难度 | 决策 | 属性 |
| --- | --- | --- |
| 球童 | 较慢反应，简单追球、普攻和射门，不主动使用复杂技能 | 正常 |
| 球员 | 原有基础传球、接应、攻击和技能决策 | 正常 |
| 球神 | 更快反应，判断拦截线路、瞄准门内空档、提前传球给移动接应者、分散接应和回防；保留资源并争抢虚弱持球者 | 正常 |
| 作弊者 | 与球神相同的决策 | 仅机器人生命／能量上限 +25%，基础移速 +12%，生命／能量恢复速度 +15% |

作弊者增益是这一版可调原型参数。真人属性不加成，不改变碰撞半径、球权判定或技能费用；前三档也不修改角色属性。机器人只读取公开场上状态，不读取玩家未执行的输入。难度的体感和强弱差距仍需真人试玩调优。

## Alt 快捷信号

按住 Alt 打开五向托盘，移动鼠标到相应扇区，松开发送：上方进攻、右上射门、右下给我传球、左下防御、左上注意。中央松开或 C 取消；边缘会调整托盘位置，使整个托盘留在窗口内。按住但未移动不会误发信号。

信号的位置取打开托盘时的鼠标位置，可直接指向场地、球员或小地图；指向球员时标记跟随该球员。“给我传球”始终标记发送者本人。场上显示发送者及文字，小地图显示对应的攻／射／传／守／! 标记，4.5 秒消失。每人最多每秒发送一次，画面最多保留 8 条。

联机只向同队转发，由房主校验身份、比赛编号、坐标、信号类型和频率。敌队不会收到信号。打开托盘和松开的当帧不提交新的踢球、推抢或技能输入；已经执行的移动指令继续有效，正在准备的传射／技能会取消，避免托盘操作误触出手。

## 观察与数字编队

- 左键点击小地图球员头像：镜头跟随对应队友或敌人。点击空白位置：观察该处球场。
- 鼠标指向场上球员或小地图头像，按 Ctrl＋1–9：把这个球员绑定到对应编队。也可以先在小地图选择球员，再按 Ctrl＋数字绑定。
- 单按数字选择对应编队；0.32 秒内连续按同一个数字两次，镜头切到并跟随该球员。
- 默认按反引号 ` 键回到自己，空格仍为推抢。Alt 和回到自己的按键可在设置中修改；Ctrl 与数字 1–9 保留给编队。
- 观察只改变本机镜头，不转移操控权。编队跟随球员槽位，倒地复活后仍有效；新的一局清除编队、信号和观察状态。

## 开发与验证

规则入口：`OpeningArea`、`BotDifficulties`、`BotTactics`、`TacticalSignal`、`ObservationGroups`。表现和输入入口：`OpeningShieldView`、`MatchTacticsUI`、`MatchMiniMap`、`ArenaCamera`。机器人难度与信号沿用 LAN、互联网和 Steam 共用的房主权威房间协议。

协议升级为 `SkillSoccer/0.28.0/9`，双方必须使用相同版本。规则、网络和实际渲染客户端报告位于 `reports/tactics-028-*`。客户端专项使用受控的输入采样接口验证操作、真实相机和 UI，不能视为实体键鼠、Windows 实机或两个真实 Steam 帐号跨公网的验证。
