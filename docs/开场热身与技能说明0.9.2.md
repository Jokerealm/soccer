# 开场热身与技能说明 0.9.2

2026-10-10。开场 3 秒倒计时允许移动和鼠标转向，足球留在中心防护罩内；缩小常驻底部面板，技能详情按悬停显示。

## 开场热身

`MatchState.IsOpeningWarmup` 表示比赛第一次开场倒计时。角色可以用正常移动速度走位、转向，机器人也会轻微热身走动；有效比赛时间保持不变。倒计时期间动作输入不会造成攻击、技能、铲球、蓄力或资源消耗，也不会缓存成开球后的动作。

足球周围的防护罩半径默认 1.25，由 `MatchRules.OpeningShieldRadius` 配置。Core 使用防护罩半径加角色半径作圆形阻挡，检查扫掠移动，允许沿罩体滑动，并在身体分离后校正侵入。接球也检查比赛阶段。球保持静止且无持球者；R/F/T 训练快捷键和训练按钮在开场热身期间不能绕过保护。

场景中显示青绿透明半球、边缘光、细网格、缓慢扫描和地面圆环；这些网格只负责展示，阻挡来自 Core。暂停同时冻结场景动画与开场倒计时。倒计时结束，罩体与规则阻挡同时解除，保留热身后的位置，正常接球和战斗输入恢复。

本轮热身适用于首次开场和重新开始一场比赛。进球后的输球方发球、发球保护及恢复流程继续采用现有规则。

## 底部面板与悬停说明

完整面板缩小：头像由 94 缩至 60 UI 像素，技能框由 72 缩至 54，生命／能量条由 21 缩至 16；收起常驻操作帮助及移速信息，缩小留白。保留技能名、快捷键、消耗、弹药、冷却和资源数值。完整／精简模式和设置保存继续可用。

技能浮层在鼠标进入 Q、E、G、踢球、铲球或武器图标时显示，离开后关闭；以短淡入呈现。浮层显示当前角色的描述、实际配置的冷却／消耗，以及当前就绪、冷却、装填或资源不足状态。枪兵、雷神的技能内容分别读取装备配置。

浮层固定在对应图标上方，约束在窗口内，不获取鼠标点击。悬停技能图标时暂停足球瞄准和鼠标攻击采样，WASD 移动仍可用。切换精简 HUD、暂停或离开比赛时清除浮层。
