# 联机名字与房间界面 0.27.0

2026-10-14。登录后使用独立游戏名字，联机入口以房间列表为主，队伍在房间内选择。

## 玩家操作

1. Steam 或联网帐号首次在本机登录，先设置游戏名字。名字为 1–6 个字；中文、英文和数字都可用，空名字和超过六字的名字不能保存。
2. 首页 → 个人主页 → 修改名字，可保存新名字或取消。游戏名字用于个人主页、首页帐号提示、房间成员和房主名称，不再直接使用 Steam 昵称。
3. 联机对战直接打开房间列表。Steam 登录后默认浏览 Steam 房间，列表显示房间名称、房主游戏名、占用位置 `/6`、真人数和机器人数量。有密码的房间显示金色 🔒 锁标志。
4. 点击列表中的“加入”：无密码房间直接连接，有密码房间先打开密码弹窗。按房间号加入时，只需点击“加入房间”，然后输入六位房间号；必要时会提示输入密码。密码仍是遮挡输入，不保存到档案。
5. 进入房间前无需选择队伍。系统先分配可用位置，进入后通过“你的队伍”选择青队或橙队。换队后全员取消准备，队伍已满时提示并保留原位置。
6. 创建房间仍可设置房间名称和密码，房主手动添加机器人；满六个位置且全员准备后倒计时进入选人布阵。

名字按 SteamID／联网帐号分别保存在当前设备，重开游戏仍保留；离线档案默认使用“离线球员”，也可从个人主页修改。当前名字与金币、战绩一样尚未跨设备云同步。

## 版本与验证

房间协议升级为 `SkillSoccer/0.27.0/8`，两端必须更新到 0.27.0。新版本握手由房主分配可用位置，并把最终位置纳入密码／帐号证明；并发加入会预留位置，避免重复占位。0.26.1 的搜索阶段房主校验修复继续保留。

验证包括名字持久化和帐号隔离、六字限制、同时自动加入及容量限制、换队与准备状态、实际 Steam 登录与大厅元数据、锁标志和密码弹窗、客户端窗口布局及双进程实际入房。完整结果见 `reports/rooms-027-validation.json`。Steam 原生回环测试使用隔离的第二房间身份，不代表 0.27.0 两个真实 Steam 帐号或公网／SDR 路径已经验证。

本地 Windows 包：`dist/SkillSoccer-0.27.0-Windows-x64.zip`，完整解压后运行 `SkillSoccer.exe`。
