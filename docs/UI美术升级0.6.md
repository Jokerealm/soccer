# UI 与球场美术升级 0.6

2026-10-09。按本轮要求先做好界面和游戏内 UI；角色设定与技能等待用户后续提供。本轮集中改善质感、清晰度、视觉层次和球场可读性。

## 实际接入内容

大厅与启动页使用新的城市球场主视觉，移除历史角色背景；模式卡片采用温暖的实色面板、独立模式徽章、清楚的主次字体与可用状态。普通对练标为现在可玩，排位与娱乐标为筹备中。

模式详情、装备选择、暂停、结算与设置采用同一套色彩和控件层次。金色用于主要行动，青绿色用于积极状态与选中项，暖白用于信息面板，深蓝用于球场 HUD；按钮有清晰的悬停、按下、键盘焦点和禁用状态。装备图标用于填充当前试验界面，角色画像尚未接入。

战斗 UI 改为紧凑的比分牌、生命／能量条、带矢量符号的普攻／抢断／Q／E 状态，以及传射提示。训练工具移至场地上方，减少底部面板挡住比赛区域。对话框与资源条使用实色、克制的边框和层次，避免大片透明叠加。

球场图片铺在真实 XZ 地面网格上，使用 Standard 材质、低强度自发光和实时受光；暖色主灯、青／橙两侧补光和三色环境光共同形成明暗层次。主灯投射柔和阴影，地面接收足球和球门的实际投影。看台细节仍来自图片，图片本身已有的明暗也保留。

足球改成真实球面模型：12 个深色五边形、20 个暖白六边形，共 2880 个面片三角形，接缝内层单独建模。每次位移按距离／球半径旋转，真实材质响应场景灯光，具有球面高光与暗部；落地软影与实时投影配合。球门使用三维圆柱立柱、横梁、支架和独立网格线，参与受光与投影。

边界、中线、中圈与球门位置根据实际规则绘制，独立于背景插画。相机改为 55° 倾斜正交视角，逻辑场地保持原来的二维规则；鼠标用射线与地面求交，不会因显示方式改变瞄准坐标。角色占位棋子、资源条和反馈数字使用适配新相机的显示平面。场景开启 4 倍 MSAA，非 16:9 视口外用独立清屏相机清除，避免残留大厅画面。

## 清晰度规格

| 项目 | 实际规格 |
| --- | --- |
| 大厅与球场背景 | 内置 image_gen 输出原图均为 **1672×941**，保留原文件；没有把放大输出称作原生 4K |
| 11 个模式／装备／HUD 符号 | 可编辑 SVG 源，导出 768×768 透明 PNG |
| 中文大标题 | Noto Sans CJK SC 真粗体，96 点 SDF，4096×4096 动态图集；避免依赖合成粗体 |
| 普通中文 | 既有 Noto Sans CJK SC SDF 字体，独立文字渲染 |
| 界面布局 | UI Toolkit 按 1600×900 基准缩放；文字、面板和实时标线独立渲染 |
| 纹理导入 | 上限 4096，不压缩，不生成 mipmap；这表示导入能力，不表示背景原图分辨率 |
| 默认窗口 | 1600×900，可自由改变大小 |
| 截图检查 | 1920×1080、2560×1440、1024×768、1920×800、3840×1662 的真实客户端截图 |

本轮通过原画、字体、矢量符号、三维模型和实时光影改善清晰度与体积感。macOS 窗口请求 3840×2160 时被系统限制为 3840×1662，验证报告记录实际尺寸；没有将它称为完整 4K 验收。若后续目标是每个背景细节在 4K 下也保持原生细节，需要进一步制作更高分辨率的分层场景资产。
